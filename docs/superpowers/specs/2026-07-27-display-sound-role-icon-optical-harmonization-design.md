# LMDJ Display 声音角色图标光学校准设计

- 日期：2026-07-27
- 状态：已确认；待实施
- 目标落点：`apps/web/src/assets/sound-role-icons/`
- Figma 文件：[LMDJ Ordered Signals — Sound Role Icons](https://www.figma.com/design/bYTpYVk7Bvkxs7JYR2nRlC)

## 1. 设计结论

当前八个声音角色图标已经形成统一的 `Ordered Signals` 设计语言：

- 统一使用 256×256 画布和 32 单位逻辑网格；
- 使用单色 `currentColor` 与透明负空间；
- 主要构图来自径向、镜像、四重对称和嵌套递进；
- 默认描边以逻辑 2 单位（最终 16px）为基准；
- 角色轮廓在大尺寸下已经可辨识且互相协调。

本轮只优化 **Display 版**，用于 Pad 背景和 72–112px 以上的展示场景。优化采用
光学校准，而不是结构级重画：保留所有已经确认的几何坐标、元素数量、对称关系和
声音角色隐喻，只调整部分图标的描边重量。

Micro 版仍将作为独立资产服务 16–24px 侧边栏，但不在本轮设计或实施范围内。

## 2. 光学校准参数

| 角色 | 当前参数 | Display 目标参数 | 处理理由 |
|---|---|---|---|
| Kick | 描边 2 | 不变 | 视觉重量适中，作为基准之一 |
| Snare | 实心模块；中心描边 2 | 不变 | 模块密度与 Kick 基本平衡 |
| Hat | 描边 2 | 外、中层 1.8；内层 2.0 | 三层嵌套拱门产生重复叠加；内层保持闭合黑柱 |
| Percussion | 实心圆点与中心菱形 | 不变 | 径向密度稳定，作为实心图形基准 |
| Bass | 外圈 2；波形 2.2 | 外圈 1.8；波形 2.0 | 外圈和双波形叠加后黑色面积最大 |
| Melody | 描边 2 | 不变 | 方形镜像四叶结构已经与基准重量匹配 |
| Vocal | 射线 1.8 | 射线 2.0 | 多条斜线受抗锯齿影响，大尺寸下仍显偏轻 |
| Phrase | 描边 2 | 描边 1.8 | 四层开放嵌套使右上区域视觉重量偏大 |

参数是光学值，不要求所有图标共享完全相同的数值。验收标准是相同展示尺寸下的
感知重量接近，而不是 SVG 属性数值相等。

## 3. 几何与轮廓约束

本轮不得改变以下内容：

- 任何图标的 `viewBox="0 0 256 256"`；
- 32 单位逻辑网格和整体 `scale(8)`；
- 已确认的方头、平头和尖角连接规则；
- Bass 双正弦波、圆环和四个齐平交界点；
- Melody 的 2×2 方形镜像四叶结构；
- Vocal 的 12 条放射线；
- Phrase 的四层嵌套路径；
- 图标的单色 `currentColor` 合约。

Bass 是唯一需要随线宽同步更新裁切参数的图标。外圈半径保持 12，描边从 2
调整为 1.8 后，内轮廓半径由 11 变为 11.1。波形必须继续充分越过内圆，并由
半径 11.1 的圆形裁切路径修齐，确保四个交界点没有过冲、缺口或抗锯齿裂缝。

## 4. 资产与元数据

实施只修改当前 Display 资产：

- `hat.svg`
- `bass.svg`
- `vocal.svg`
- `phrase.svg`
- 同步精灵文件 `icons.svg`
- `manifest.json`
- 必要时同步 `README.md`

`manifest.json` 版本应递增，并记录 Display 的光学线宽，而不是继续用单一
`optical_stroke` 暗示所有角色数值完全一致。

Melody 元数据必须与已确认成品同步：

- 不再使用 `rotating pitch`；
- 不再使用 `four-fold rotational`；
- 改为方形镜像、非旋转的四重秩序描述。

本轮不创建 `micro/` 目录，不新增 16–24px 专用 SVG，也不改变产品消费者。

## 5. Figma 同步

现有 Figma Display 区保持：

- Section：`LMDJ / Ordered Signals / 256`
- 4×2 排列；
- 每个图标 256×256；
- 暖白展示背景；
- 图层命名 `Icon / {Role} / 256`。

只替换 Hat、Bass、Vocal 和 Phrase 四个 SVG Frame。Kick、Snare、Percussion
和 Melody 保持原节点和视觉结果。替换后的 SVG 必须继续是可编辑矢量，不能变成
PNG、扁平截图或不可追溯的手工重建图形。

## 6. 验收标准

### 6.1 视觉验收

- 在 256px、112px 和 72px 下并排观察，八个图标没有明显的超重或过轻项；
- Hat 三层拱门仍清晰，不因减重断裂；
- Bass 双波形仍比外圈略强，但不再压过其他图标；
- Vocal 放射线与 Kick、Percussion 的径向图形保持可区分；
- Phrase 仍保留开放、递进的时间结构，但不再形成右上黑块；
- 所有图标继续符合单色、几何秩序和透明负空间语言。

24px 与 16px 只作为退化观察，不作为本轮 Display 版的最终小尺寸质量承诺。
Pattern Sidebar 在 Micro 资产完成后才切换到专用版本。

### 6.2 技术验收

- 所有单体 SVG 和 `icons.svg` 通过 XML 校验；
- 单体与精灵中的同名角色几何和线宽一致；
- `manifest.json` 可解析，描述与成品一致；
- Web 测试全部通过；
- Figma 中四个替换节点仍为 256×256，整体 Section 排列不漂移；
- 最终 Git 提交只包含本轮 Display 光学校准文件。

## 7. 非目标

- 不实现 Micro 图标；
- 不接入 Pattern Sidebar 或 Pad 组件；
- 不改变角色命名、颜色映射或 A/B 规则；
- 不创建 Figma 组件库、变量集合或 Code Connect；
- 不重新设计任何声音角色图形；
- 不合并、推送、部署或发布。
