# LMDJ Creator 使用流程（用户版）

日期：2026-09-29

状态：**目标体验**。本文描述 Creator 将要提供的使用方式，由
[内部版](2026-09-29-creator-user-workflow-design.md)派生；其中很多功能尚未实现，当前实际能做什么以内部版的"现状"一栏为准。可用于可用性测试脚本（如 [#251](https://github.com/endaye/lmdj/issues/251)）与后续使用手册的起草，不能当作已发布功能说明。

---

## 1. 认识界面

Creator 像一台乐器：

- **四个页面键**：Project（工程）、Sample（采样）、Sequence（编序）、Perform（演奏）。随时可以切换，切页面不会停止正在播放的节奏。
- **A / B / C / D 键**：切换 Pad 组，每组 16 个 Pad，一共 64 个。
- **16 个 Pad**：用来发声、录音、演奏。
- **上屏**：显示当前状态；**触控屏**：根据你正在做的事显示对应的控件。
- **System**：账号、设置、MIDI 与音频设备、扩展等，不常用的东西都在这里。

## 2. 第一次打开

1. 打开 Creator，它会自动为你新建一个工程，并停在 **Sample** 页。
2. Bank A 的 Pad 会各自下载默认声音，每个 Pad 上显示自己的进度；**哪个下完哪个就能用**。
3. **点任意一个下载好的 Pad 就能听到声音**，不需要先点"开启音频"之类的按钮。

默认声音下载一次后就保存在你的设备上，之后没网也能用。

以后再打开 Creator，会直接回到你上次的工程。一切**自动保存**，没有"忘了保存"这回事。

## 3. 放进你自己的声音

- **录音**：**按住一个空 Pad** 就开始录，松开就录好了，声音直接放进这个 Pad。第一次录音时浏览器会问你是否允许使用麦克风，允许后再按住一次即可。
  - 录音来源可以选麦克风，也可以选"现在听到的声音"（重采样）。
  - 单次最长 60 秒；完全没有声音的录音不会被保存。
- **导入文件**：**点一下空 Pad**，选一个音频文件（WAV、MP3、M4A、AAC、FLAC）。也可以直接把文件拖到 Pad 上。
- **歌曲素材（目标流程）**：像导入普通文件一样导入到一个 Pad，然后在 Sample 编辑里用 **Tools → Split Stems** 拆成鼓、人声、贝斯、其他，或用 **Tools → Chop** 切成多段。先试听，再确认把选中的声音放到建议的空 Pad 上；原 Pad 默认保留。处理时可继续演奏。首轮 Stem 评测只覆盖短片段，整曲支持尚待验证；当前交付边界见 [Stem/Slice 计划](../plans/2026-10-03-stem-slice-provider-delivery.md)。
- **声音包**：在 Project 页安装更多声音包到任意 Bank。

## 4. 调整声音（Sample）

选中一个 Pad，触控屏上有两个按钮：

- **编辑**：裁剪起止点、循环、反向、音量、音高、声像、淡入淡出、EQ、Choke 组等。
- **删除**：清空这个 Pad。删错了可以撤销。
  - 删除只会清掉声音，**你录过的节奏还在**：给这个 Pad 放一个新声音，节奏会直接用新声音播放。

Pad 正在下载或处理时按它不会出声；想换成别的声音，先删除它。

## 5. 录一段节奏（Sequence）

1. 按 **▶** 播放，按 **●** 开始录；一边播放一边打 Pad，节奏会循环，录进去的内容下一圈就能听到，可以一层层叠加。
2. 再按 **●** 结束录音，节奏继续播放；按 **▶** 停止。
3. 打错了可以撤销，或者打开网格逐个修改音符。
4. 调整速度、Swing、Quantize，开关节拍器。
5. 想把当前节奏变成一个循环素材？用 **Resample Loop**，它会被放到下一个空 Pad 上。

## 6. 现场演奏（Perform）

- 随时按住效果（Filter、Delay、Reverb、Stutter 等）即可生效，松开就取消，多个手指可以叠加多个效果；打开 **HOLD** 后，松手效果也会保持。
- 切换 Pattern 会在下一小节生效，节奏不会断。
- 想把带效果的声音存下来：按住一个空 Pad，来源选"现在听到的声音"。
- 用演奏录音把整场表演录下来，导出成 WAV。

## 7. 带走你的作品（Project）

在 Project 页：

- **导出**：整首混音、每个 Pad 一条音轨（Stems）、Ableton Drum Rack / Live Set，接着到 DAW 里继续制作。
- **分享**：导出工程文件发给朋友，对方导入后得到一份自己的副本。
- **工程库**：新建、打开、复制你的工程。

## 8. 登录与云端

- **不登录也能完整创作**，作品保存在你的设备上。
- 登录后可以：自动同步到云端、在别的设备上继续、用链接分享。你登录前做的工程可以一键归到账号下。
- 没有网络时照常创作，联网后会自动同步。
- 在两台设备上改了同一个工程也不用担心：录进去的节奏两边都会保留，其他设置以最后一次修改为准，随时可以回到之前的版本。

## 9. 出现问题时

- **切到别的窗口**：声音继续。
- **切走标签页或锁屏**：播放会停下并记住位置，回来后点一下任意地方就能继续。
- **录音时被打断**：已经录到的部分会保留。
- **同一个工程在另一个标签页打开了**：可以选择"在这里继续"。
- **页面意外关闭**：下次打开时会问你是否保留被打断的录音。
- **出错时**：界面会用简单的话告诉你发生了什么、该怎么做；你的工程不会受影响。错误信息可以自动发送给我们用于改进（可以在设置里关闭，不包含你的声音和作品内容）。
