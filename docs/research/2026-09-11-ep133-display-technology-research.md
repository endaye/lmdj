# EP-133 显示面板工艺与 LCD OLED 屏幕对比研究

> 研究日期：2026-09-11。
> 对象：Teenage Engineering EP-133 K.O. II 中央显示面板，以及实现相似效果的通用工艺。
> 文档性质：公开资料研究与工程分析，不是硬件选型、供应商推荐或实施承诺。
> 证据边界：没有拆机、测量光谱、辨认油墨或获取生产 BOM；不能由外观照片确定完整材料层叠。
> 用户提供的图片标有 128 MB；早期报道只能佐证产品显示方式，不能证明后续批次每个元件和材料都未改变。

## 1. 核心结论

**EP-133 的显示面板属于定制分段、固定图标显示；它不是手机式、可以逐像素绘制任意图像的通用彩屏。**
官方把它称为 “super segment hybrid display”，手册明确说明有 66 个独特图标。
iFixit 在直接采访 TE 硬件负责人 David Eriksson 的报道中，将其描述为分段 LED 显示。
[官方产品页][s1]、[官方屏幕说明][s2]、[iFixit 采访][s3]

决定显示自由度的关键是：**硬件预先定义的是整块图标和笔画，还是可独立控制的像素阵列。**
两种方式都有预制结构，但固定的内容不同。

| 问题 | EP-133 这类显示方式 | 手机式彩色图形屏 |
| --- | --- | --- |
| 制造时固定什么 | 图标位置、轮廓、数字笔画及可控制的区域 | 像素位置、子像素结构和面板规格 |
| 软件决定什么 | 哪些预设部分点亮、何时点亮，以及组合与动态 | 每个像素的颜色和亮度，再组合成文字与图像 |
| 新增一个原来没有的图标 | 通常要改图案层；若超出现有分区，还要改光学或电路结构 | 在分辨率与软件能力内更新图形资源即可 |
| 能否重新排版或显示照片 | 无法变成任意图形画布 | 可以，但仍受分辨率、色域和刷新能力限制 |

因此，“里面能显示什么，是提前做好的”基本正确；“所有颜色一定都压制在同一层上”则超出了现有证据。
更稳妥的表述是：**固定图案与 LED 发光区域共同形成显示，配色不是手机式任意 RGB 画布。**
具体哪些颜色来自透光图案、哪些来自发光元件，需要进一步材料或拆机证据。

## 2. EP-133 已知事实与证据边界

本文将信息分成三类：**公开确认**有官方资料或直接采访支持；**工程解释**是同类方案的工作原理；
**未知**表示本次资料不能支持更具体的结论。

| 判断 | 证据等级 | 可以确定到哪一步 |
| --- | --- | --- |
| 定制显示面板，有 66 个独特图标 | 公开确认 | 来自官方手册；66 不是 LED 数量、驱动通道数或全部显示段数 |
| 分段 LED 显示方式 | 公开资料支持 | iFixit 直接采访报道的技术描述；不是器件型号清单 |
| 中央数字由预设笔画组合 | 外观与功能证据支持 | 可组合数字及受限字符，不应据此推断具体封装和驱动芯片 |
| 图案透光层配合分区 LED 可以实现此类视觉效果 | 工程解释 | 有面板制造商的工艺资料支持，不等于已取得 EP-133 原厂工艺卡 |
| 所有光源都是白色 LED，所有颜色都来自印刷 | 未知 | 不把论坛说法或相邻型号拆机直接当作本机全批次事实 |
| 膜材是 PET 或 PC，采用某种丝印油墨 | 未知 | 这些是通用候选材料和工艺，照片无法鉴定 |
| “hybrid”就是 LCD 与 LED 混合 | 未确认 | 官方名称不足以定义内部技术组合，不能从名称自行展开 |

官方手册也描述了在显示区域呈现 `RES`、`SET` 等状态字符。
因此“图案固定”不等于“只会显示一种内容”：数字段可以重新组合，预设图标可以按时间变化。

## 3. 固定图标 LED 面板通常如何制造

### 3.1 功能结构

可以将同类方案理解为一组小型、可分别控制的透光标志。下面按功能分解，
**不是 EP-133 实测剖面，也不代表各层一定是独立零件或采用这个精确顺序**。

```text
观看者
  ↑
保护视窗／深色外观层        保护表面，减弱未亮图案的可见度
  ↑
预制图案与透光着色层        决定轮廓，必要时提供固定颜色
  ↑
扩散与隔光结构              让区域内发光均匀，避免相邻图标串光
  ↑
分区 LED 与电路板           提供光，控制哪些区域亮起
  ↑
驱动电路与固件              将设备状态映射为亮灭、亮度或时序
```

业内常见术语是 **graphic overlay（图形覆膜／面板）**、**backlit icon（背光图标）**，
以及 **dead-front / hidden-until-lit（未点亮时隐藏图案的外观处理）**。
Dead-front 描述的是外观效果，并不是与 LCD、OLED 并列的一种发光材料。
它也可以与其他显示和触控方案组合。[JN White 工艺说明][s5]、[Abrisa 工艺说明][s6]

### 3.2 图案与颜色怎样形成

典型做法是在透明基材上形成不透光背景和可透光的图案窗口。背景挡住光，窗口显出符号。
需要固定配色时，可以加入透光彩色层；也可以使用有颜色的 LED，或组合两者。
JN White 明确说明其同类面板的颜色通常来自图形覆层，并介绍了数字印刷与丝网印刷结合的生产方法。
**这证明工艺可行，不证明 JN White 是 EP-133 供应商。**[JN White 工艺说明][s5]

“提前压制好”不是最精确的工艺称呼。实际可能涉及印刷、涂层、切割、贴合和塑料件成型；
其中只有某些结构件需要模具。若不掌握原厂工艺，宜称“预制透光图案”，不要直接指定为注塑、压印或某种丝印。

例如，一个彩色小人可以整幅印在一个透光区域内，由背后的光照亮。
即使看起来有很多彩色细节，这些细节也未必能够被分别控制。**视觉上的细节数量不等于电子控制点数量。**

### 3.3 典型制造流程

以下为参考方案的工程分解，不是 EP-133 生产线记录。

```text
定义显示状态与图标分区
  → 制作图案稿与透光／遮光分色稿
  → 制作并印刷面板，检查颜色与套准
  → 制作扩散、隔光和支撑结构
  → 电路板制造、LED 与驱动器件贴装
  → 对位组装
  → 检查均匀度、串光、灭灯外观和动态显示
```

这条路线在成品装配层面接近“精细图形面板＋光学结构＋电子装配”。
它仍然使用由半导体工厂制造的 LED 和芯片，不能理解为整条供应链都不涉及半导体工艺。

## 4. 普通 LCD 与 OLED 的工艺有什么不同

这里的“普通屏幕”主要指可绘制任意图形的彩色 TFT LCD 和 AMOLED。
**LED、LCD、OLED 是光源或成像机制的分类；分段和点阵是显示组织方式的分类，两组概念不能互相替代。**
LED 点阵也能显示图像；使用 LED 背光的 LCD，图像仍由液晶层调制。

### 4.1 TFT LCD 把大量可控制的光阀做在玻璃上

LCD 的液晶层本身不发光。典型透射式彩屏由背光提供光，液晶、电极和偏光片共同调节透过量，
再经彩色滤光结构形成颜色。薄膜晶体管（TFT）负责控制像素。
[Samsung Display TFT 原理][s7]

其面板制造可以分为阵列、彩膜、液晶盒和模组装配：

1. 在基板上通过薄膜沉积、光刻、刻蚀等工序形成 TFT、电极和走线。
2. 制作黑矩阵和 RGB 彩色滤光结构；TOPPAN 介绍的典型路线是涂布感光材料、曝光、显影和固化。
3. 将基板对位成盒，形成液晶层和受控间隙，封装并贴附偏光片。
4. 连接驱动芯片与柔性电路，组装背光、框架并测试。

这是典型制造逻辑，不是所有厂商的唯一配方；引用的 Hitachi 资料用于解释基础工艺，
不用于推断当前工厂的光罩数量、价格或产能。[Hitachi 制造资料][s8]、[TOPPAN 彩膜工艺][s9]

关键差别是：LCD 制作的是可以反复组成不同图案的像素结构，
不会把“播放三角形”直接做成唯一可显示的轮廓。

### 4.2 AMOLED 把可控制的发光单元做在基板上

AMOLED 使用有机发光层形成像素，由有源矩阵驱动，通常不需要 LCD 式背光。
典型手机 RGB OLED 路线包含背板制作、有机薄膜蒸镀、封装、切割和模组装配。
精细金属掩膜可用于限定不同发光材料的沉积位置；封装用于阻止水汽和氧气破坏有机层。
[Samsung Display 蒸镀说明][s10]、[封装说明][s11]

```text
固定图标 LED 参考方案：图案面板制作 + LED 电路装配 + 隔光扩散 + 对位
TFT LCD 典型路线：     TFT 阵列 + 彩膜 → 液晶盒 → 驱动连接与背光模组
AMOLED 典型路线：     TFT 背板 → 发光薄膜 → 封装 → 切割与模组
```

OLED 并非只有这一条制造路线，不同尺寸和产品还可能采用不同背板、彩色化方式或印刷方法。
上述步骤解释的是与手机式显示相关的典型方案，不应推广为所有 OLED 的唯一结构。
[OLED Cell 制造说明][s12]

### 4.3 计算器的段码 LCD 是另一种情况

段码 LCD 同样预先固定数字笔画和图标，但通过图案化透明电极与液晶层切换可见状态，
而不是让 PCB 上的 LED 直接照亮每一个图案。它可利用环境光，也可配背光。
因此，外观像计算器、只能显示预设符号，并不足以判断某面板是不是 LCD。
[Focus LCDs 段码玻璃设计指南][s13]

EP-133 应结合前述产品资料识别，不能仅因为数字长得像计算器，就归入段码液晶。

## 5. 显示能力与工程代价对比

下表是通用架构比较，固定图标列不表示已取得 EP-133 的全部电气规格。

| 维度 | 固定图标 LED 面板 | 彩色 TFT LCD | AMOLED |
| --- | --- | --- | --- |
| 显示单元 | 图标、笔画或固定区域 | 可寻址像素／子像素 | 可寻址发光像素／子像素 |
| 图形自由度 | 受物理图案与分区限制 | 分辨率内可自由绘图 | 分辨率内可自由绘图 |
| 颜色控制 | 由光源、透光层和驱动能力决定 | 调节彩色子像素的透光量 | 调节发光子像素的发光量 |
| 动画 | 预设元素的时序与组合 | 任意可渲染帧 | 任意可渲染帧 |
| 文字与多语言 | 数字段字符有限；固定文字难更换 | 可通过字库与软件更新 | 可通过字库与软件更新 |
| 改版重点 | 图案、隔光结构、必要时电路 | 通常改 UI 软件与资源 | 通常改 UI 软件与资源 |
| 光学工程重点 | 均匀照明、串光、灭灯隐藏、套准 | 背光、液晶光学、视角与面板均匀性 | 发光均匀性、封装与使用寿命 |
| 功耗主要变量 | 点亮区域、LED 电流、占空比和光损耗 | 背光亮度、驱动和刷新方式 | 画面亮度、内容、驱动和刷新方式 |
| 软件资源 | 可只维护区域状态；不必有完整帧缓冲 | 需像素数据；可用局部更新或模组显存 | 需像素数据；具体取决于接口和模组 |

工作原理依据：[面板印刷][s5]、[TFT 与 LCD/OLED 原理][s7]、[OLED 封装][s11]。
改版和资源开销属于基于这些机制的工程分析，不是实测性能排序。

### 5.1 能做动画，不等于能播放任意视频

把圆环的几个区域依次点亮，就能产生旋转感；让小人不同姿态轮流出现，也能产生动作感。
这些是固定元素的时序动画。它们不意味着存在足以显示任意照片的像素阵列。
此处是原理举例，不对 EP-133 每个图标的具体分区和动画能力作未经验证的断言。

### 5.2 高精细图案，不等于高分辨率图形屏

印刷图案可以有细线、复杂轮廓和多色细节，肉眼看起来很精致；
软件可能只能整体点亮它。用“多少像素”衡量这类面板往往不合适，
应关心可独立控制的区域、最细可制造线条及光学效果。

### 5.3 软件开销的数量级示例

仅为理解差异，假设一个方案有 100 个独立开关区域，只存亮灭状态需要约 13 字节；
若每区用 8 位记录亮度，则是 100 字节。一个假设的 320 × 240、RGB565 图形帧需要
`320 × 240 × 2 = 153,600` 字节，即 150 KiB。

这些数值是计算示例，**不是 EP-133 的通道数或内存测量**，也不是系统总 RAM 对比。
图形模组可以自带显存，主控可以分块渲染；固定图标也需要驱动与状态管理。
减少显示开销不会自动解决音频处理的内存或算力需求。

## 6. 成本和开发难度不能只看屏幕是否通用

**“面板工艺更简单”与“买到手更便宜”是两件事。** 面板工厂制造 TFT LCD、AMOLED 的设备和工艺复杂，
但设备开发者通常采购现成模组，不必自己建屏幕工厂。固定图标方案虽然可以使用通用 LED 和驱动器，
仍需承担专属图案、光学件、工装、对位装配与测试成本。

可以用下面的工程估算框架比较方案，本文没有供应商报价：

```text
每台摊销成本 ≈ 材料与器件 + 装配 + 测试 + 不良损耗
             +（设计、打样、模具、工装等一次性费用 ÷ 实际产量）
```

| 场景 | 固定图标方案的意义 | 需要考虑的代价 |
| --- | --- | --- |
| 少量原型、功能还在变化 | 可以先验证独特外观 | 定制与返工可能比购买标准彩屏更费时费钱 |
| 图标稳定、产量足够 | 一次性投入可以摊薄，显示逻辑可简化 | 要计入 LED 数量、结构件、装配良率及库存 |
| 多语言、文件浏览、波形编辑 | 只适合有限状态提示 | 固定文字和有限数字段会限制信息表达 |
| 长期延续同一视觉语言 | 图标位置稳定，容易建立操作记忆 | 后续功能必须适配旧分区，或付出硬件改版成本 |

iFixit 的直接采访能支持 TE 当时重视通用零件供应和自建生产线这一背景；
它不能提供显示面板的独立成本，也不能证明这种方案一定比 OLED 便宜。[iFixit 采访][s3]

同样，不能直接断言固定图标方案“必然更省电”“完全不闪烁”或“延迟一定更低”。
亮度、同时点亮的区域数、扫描驱动、PWM、光学损耗和 UI 更新策略都影响结果。
若要比较，应在相同可读性和使用场景下测量，而不是仅比较技术名称。

## 7. 想实现类似效果时应该关注什么

以下是后续设计与验证建议，不代表已经为 LMDJ 选择显示硬件。

### 7.1 区分视觉借鉴和物理复刻

如果需要的是 EP-133 那种固定布局、彩色符号和状态动画，普通图形屏也能用软件模拟。
软件方案还保留调整布局和文字的空间。若需要真实的透光材质、未亮时隐藏图案的效果，
才需要进一步比较图形面板、LED 分区和光学结构。

视觉相似不代表物理表现完全相同。玻璃反射、视角、黑色外观、图案边缘和光在材料内部的扩散，
都可能形成普通屏幕截图无法完全表达的差别。

### 7.2 用显示需求指导打样

先列出必须显示的状态、数字范围、文字语言，以及哪些区域需要独立变化。
把“未来必须显示任意波形或文件名”与“只显示录音、播放、电平”等需求分开，
再决定固定图标是否足够。不要先复制外观，再发现硬件没有容纳必要信息的位置。

若进入工艺验证，样片应覆盖以下可观察的问题：

- 相邻图标一亮一灭时，是否发生串光或误读。
- 小图标与大区域是否均匀，有没有明显 LED 热点、阴影或印刷错位。
- 在室内、强环境光和斜视角下，亮起与未亮区域是否容易区分。
- 调暗和动态切换时，肉眼与相机是否观察到闪烁或扫描条纹。
- 预定最亮画面下的功耗、温升，以及擦拭、老化后的外观变化。

均匀照明和未点亮时隐藏是同类制造商明确提出的要求；其余为工程验收建议，
不表示已经观察到 EP-133 存在这些缺陷。[JN White 工艺说明][s5]、[Abrisa 工艺说明][s6]

供应商沟通可使用“定制背光图标面板”“透光印刷面板”“dead-front graphic overlay”
“LED 隔光与扩散结构”等描述。不要仅说“定制 LED 屏”，否则可能被理解成通用 LED 点阵大屏。

## 8. 对最初几个问题的直接回答

| 问题 | 回答 |
| --- | --- |
| 它是不是通用 LED 屏 | 是定制分段／图标显示，不是通用像素画布；“LED”本身不决定是否通用 |
| 显示内容是否预先做好 | 图形轮廓和可控制区域基本预设，软件选择组合与时序 |
| 颜色是否预先做好 | 应按预设配色理解；每一区域的颜色来源不能仅凭照片确定 |
| 是不是和手机屏幕不一样 | 是。手机式图形屏控制像素，可在显示能力范围内绘制不同内容 |
| 固件更新能增加显示内容吗 | 可复用已有笔画和图标表达新含义，不能凭空增加物理上不存在的显示区域 |
| 能不能说就是“彩色印刷片后面放灯” | 适合理解通用原理，但过于简化光学和驱动工作，也不是原厂完整材料结论 |
