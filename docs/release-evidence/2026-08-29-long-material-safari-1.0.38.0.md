## Blocking failure

`LM-REJ-COMMIT-PLUS-4B` entered the long-source editor as a mono, 48 kHz,
approximately 349.53-second selection containing 16777217 frames. Selecting
`Commit selection` blanked the Creator surface. The page stayed blank for more
than 30 seconds while its WebContent process remained alive. Safari Web
Inspector reported:

```text
TypeError: Sample snapshot error details are invalid
```

Reloading recovered the Creator. The local Project was still revision 1 with
zero Assets and zero assigned Pads, confirming that the failed commit was
non-destructive. The reload was nevertheless required and therefore violates
the #359 acceptance rule.

Code inspection localized the visible failure to the Creator sample-state
error normalization path: quota-operation details reached a path that rejected
them as invalid snapshot details. This evidence record does not change that
code or settle the precise upstream contract defect; the repair needs a
separate implementation Task and regression coverage for the Browser-to-Creator
quota-error bridge.

## Memory-method limitation

Safari Web Inspector Timelines Memory was opened during the run, but the
displayed aggregate included a separate Inspector WebContent process and was
not usable as numeric page-only evidence. The table therefore records only the
Creator page process footprint. The Inspector process was excluded from every
page value.

Because the normal-boundary fixture, every lifecycle sequence, and the physical
iPadOS row remain unperformed, this session cannot establish either the
`baseline + 536870912` peak ceiling or the 30-second
`baseline + 67108864` release ceiling. The fixed Wasm heap identity is proven
by the packaged manifest; committed-PCM residency was not reached in the
failing fixture and remains unverified physically.
