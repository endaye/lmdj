`9206ef95` and `c41bcac9` changed two projected files
(`apps/architecture-portal/docs/core/modules/web-runtime-platform.mdx` and
`apps/architecture-portal/docs/operations/version-and-release.mdx`). Its
predecessor commit cleared the stale snapshot frozen at `98e63bc8`.

Provenance is decided from the landed tree, not from ancestry:
`apps/architecture-portal/scripts/check-snapshot-projection.mjs` over the
squash range `da52ff4e..98ffec72` reports `portal snapshot projection: valid`.
No squash witness is required, because no post-freeze commit on the branch
touched a projected file. See
[`squash-witness-provenance`](../../.agents/pitfalls/squash-witness-provenance.md).
