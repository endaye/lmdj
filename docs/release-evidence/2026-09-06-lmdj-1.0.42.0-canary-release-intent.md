## Full exact-main CI evidence

The Integration Queue merges with `GITHUB_TOKEN`, and GitHub suppresses the
workflow runs that such a push would otherwise trigger. The squash therefore
produced **no** `push` event `Core CI` run for the target SHA, which the
canonical audit would report as `unverifiable` rather than accept.

`ci.yml` was therefore dispatched with an empty `lanes` input while `main` HEAD
was still exactly the target SHA, which is the remedy the release skill
prescribes. An empty `lanes` input produces a `full` manifest; a lane selection
would produce a `requested` manifest and is rejected.

### Snapshot provenance through a source-tree witness

The snapshot was frozen from the Task 10 integration commit `94ba5938`, which a
squash merge rewrites, so the recorded source revision never becomes a `main`
commit. `apps/architecture-portal/versioned_provenance/version-1.0.42.0-squash-witness.json`
authenticates the divergent squash:

| Field | Value |
| --- | --- |
| `product_build` | `1.0.42.0` |
| `source_revision` | `94ba5938aea123f3305217976429ccdd8af76c40` |
| `introducing_revision` | `0ffa77c0c4f786dc5d9b285f272abe1725250b8d` |
| `source_tree` | `278f3cf26a97a91654367d4e6406975d28f8b14c` |

It was written by `scripts/architecture-portal.sh witness 1.0.42.0
0ffa77c0c4f786dc5d9b285f272abe1725250b8d` and landed on protected `main`
through PR [#682](https://github.com/endaye/lmdj/pull/682), which closed #438.
`scripts/architecture-portal.sh check` then reports
`Product Build 1.0.42.0 snapshot matches repository truth` with schema-2
provenance authenticated through that witness.

A local `check:release-docs` run inside the worktree that produced the branch
can pass *without* the witness, because that repository still holds the
pre-squash source commit object and the verifier resolves it directly. A fresh
clone and CI do not, so the witness is required. Treat a local pass in the
authoring worktree as inconclusive for post-squash provenance. See
[`squash-witness-provenance`](../../.agents/pitfalls/squash-witness-provenance.md)
and [`portal-snapshot-not-deferrable`](../../.agents/pitfalls/portal-snapshot-not-deferrable.md).
