WebKit navigation that never returns ([#1570](https://github.com/endaye/lmdj/issues/1570)).
The suite passed on this exact target, and the test-side cause found from the
retained `/proc` snapshot is fixed on `main` after this target, in PR
[#1578](https://github.com/endaye/lmdj/pull/1578). The issue stays open; it is a
test-harness defect and no product code is involved.

`performance_writer_lease_stress` mutual-exclusion failure observed on
2026-09-20 under local load on the bare-metal stress runner; the stress suite
passed on this target.
