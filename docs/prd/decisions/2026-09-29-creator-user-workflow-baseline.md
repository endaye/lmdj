# 已确认：Creator 用户流程先对齐 Koala，Project 标签定位为进出口与工程库，离线必须可用

- 日期：2026-09-29
- 关联：2026-09-29 Creator workflow 评审；完整对照见
  [Creator 用户操作流程（内部版）](../../design/2026-09-29-creator-user-workflow-design.md)。
- 解决的问题：[#534](https://github.com/endaye/lmdj/issues/534)
  （离线可用是硬需求还是可选便利），同一 Task 删除
  `questions/offline-operation-requirement.md`。

## 结论

1. **先对齐 Koala，再优化。** Creator 交互未定时默认采用 Koala Sampler 的做法（参照其官方手册）；功能全部对齐后，再针对 LMDJ 用户优化体验。与 Koala 的差异必须显式列出；架构不变式不因对齐而放松。
2. **导航。** 页面键保持 Project / Sample / Sequence / Perform 四个。账号、设置、MIDI 与音频设备、Provider 选择与安装、诊断放在不占页面键的 **System** 次级入口。社区首版只作为 Project 里的"分享"操作，是否独立成页以后再定。
3. **Project 标签 = 进出口 + 工程库 + 内容包。** 进：导入 `.lmdj` 或他人分享的工程、安装内容包；出：导出与分享；工程库：新建、打开、复制。不设单独的"导入歌曲"入口。放在 Project 页的内容不因此属于 Project Truth：账号、设备、Provider 选择与素材库是账号或设备级状态。
4. **首次使用。** 自动新建工程并停在 Sample 页，之后自动回到上次工程；全部自动保存，"另存为"即复制工程。第一次触碰 Pad、按键或开始录音时顺带激活音频。
5. **默认 Sound Set。** 放在独立资产服务器，打开时下载，不随程序打包；装进 Bank A；每个 Pad 独立下载、独立显示进度，完成后原子写入工程并存进本机，之后离线可用；首次预装不弹安装对话框。
6. **Pad 行为。** 按住**空** Pad 录音，来源可选麦克风或主输出（重采样），松开即写入；下载中、处理中与失败的 Pad 不算空，不出声，可删除。删除与编辑是触控屏上针对选中 Pad 的两个按钮；删除直接生效、可撤销，并**保留**引用该 Pad 的 Pattern 事件；被删 Asset 的物理清理在后台进行。
7. **Sample** 的编辑能力以 Koala Sample Editor 为基准，缺口逐项开 Issue。Chop 与 Split Stems 并入 Sample 编辑的 Tools，移除独立的 Slice 模式；结果依次放到空 Pad、原 Pad 默认保留、空位不足先提示；处理在后台进行。Chop 本机运行，Split Stems 本机与云端均可，由 Provider 选择决定。
8. **Sequence**：撤销与网格编辑为高优先级缺口。**Perform**：FX 随时可用，录音与 FX 是两个独立开关；带 FX 的重采样走"按住空 Pad、来源选主输出"。
9. **导出**以 Koala 主菜单为准，放在 Project → 出：Stems、Ableton Drum Rack / Live Set、`.lmdj` 分享等。
10. **出错与恢复**：窗口失焦不中断；切走标签页或锁屏时停止播放并记住位置，回来后第一次触碰自动恢复；录音被中断时保留已录部分；第二个标签页可接管工程；重开时主动询问是否保留被打断的录音；界面错误信息使用用户语言。错误**自动上报**（上传并在服务端分类）与**用户提示**是两个独立功能，内容不同。
11. **账号**：不登录也能完整创作，云功能（同步、跨设备、分享链接、协作、云端 Provider）受限且必须明确显示；登录后可认领本机工程。
12. **离线必须可用（解决 #534）**：首次打开需要联网；之后创作、工程、已下载声音与本机 Provider 在离线时照常工作；需要网络的功能明确显示不可用，不允许静默消失。
13. **可安装 Provider** 指可安装的代码；方向是隔离的进程外 Provider Host 或服务端，保持 Core 的 closed world。
14. **协作分三阶段**：单人 + 文件分享（对齐 Koala）→ 登录后同一人多设备同步与 fork 式分享 → 多人协作（先异步）。用户可见行为：参数以最后一次修改为准并保留版本历史，Pattern 事件两边都保留，离线后自动合并，撤销只撤销自己本设备的操作，演奏中的远端修改在下一小节生效。
15. **工程文件与声音资源分离**：工程文件只含 Project Truth 并以内容哈希引用音频，声音资源单独存储；`.lmdj` 降级为导出与归档格式。

## 原因

- Koala 是对标产品，先得到已知可用的基线，再按 LMDJ 自身情况偏离，风险最低。
- 现状第一步就卡住：打开后只能导入 `.lmdj`，不能新建工程，音频也必须先开工程再手动激活，与"约三分钟得到可演奏 Pad 并录出第一个 Beat"的承诺冲突。
- LMDJ 定位是"AI 生成 → 可演奏层 → DAW"中间层，Project 标签作为进出口有 Koala 不需要的理由；低频的系统功能占用页面键会破坏硬件布局的一键直达。
- 离线可用是网页版之后接入云同步与协作的前提条件；没有它，工程格式与 Provider 的运行位置会被各自分别默认。

## 影响

- 本条只记录产品结论，不修改 Contract、Facade、Host 接口、版本身份或 Portal。
- 以下结论需要独立的 Contract / 架构决策后才能实施：工程同步与协作格式、`.lmdj` 降级、Asset 清理规则、可安装 Provider、撤销系统（替代 S8-D4 "Stage 8 不引入通用 Undo/Redo"）、错误上报隐私边界、演奏中远端修改的生效时机（并发语义）。
- 与 [UI 迁移计划](../../plans/2026-09-11-creator-ui-migration.md)、U0 设计稿与 working-prd 中已过期的描述，列在内部版 §14，由后续 Task 更正。
