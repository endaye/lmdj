# 已确认：Sequence ENC1 滚动小节，↑/↓ 选择当前 Pad

- 日期：2026-10-09
- 来源：owner 对 Sequence 具体映射回复「采用」；部分解决 #1822。
- 结论：ENC1 每一格按当前网格的实际宽度横向滚动一小节，在两端停止。
  ↑/↓ 按 A01–D16 顺序选择当前 Pad，跨 Bank 同步 Bank 与上屏八行窗口；
  A01 不能再向上、D16 不能再向下。当前 Pad 仅高亮，不触发声音，不改变
  音符选择，不写入 Project Truth。

  页的具体对象和边界明确下来。
