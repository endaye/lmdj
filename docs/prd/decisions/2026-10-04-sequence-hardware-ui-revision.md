- 依据：Figma Desktop Final 文件 `GPFarNiZNsjLQzfG9kR8DO` 的 D02 · Sequence 画板（节点 88:706）。其中上屏为 88:819，触控区为 88:1512，Pad 矩阵为 88:1376，D02 开发说明为 91:746。另有 owner 2026-10-03 至 10-04 对当前 Creator Web 实现与 D02 的对比评审，评审用一个可操作的效果页验证了下列结论。

## 结论

1. **上屏采用 D02 的轨道总览样式，一次显示 8 行，可以滚动。** 仍然只读，不接收触摸。
   - 字体统一用 IBM Plex Mono。
   - 主状态行：`SEQUENCE / NN`、BPM、Swing，以及右侧的传输状态加小节:拍位置，例如 `STOPPED / 001:01`。
   - 上下文行：小节范围与步数、吸附精度、当前显示的行范围（如 `TRACKS A01–A08 / 64`）、当前 Bank；有选中音符时显示选中数量与力度。
   - 每行 10 px 高、行距 3 px。左侧是窄的行名列，右侧是整个 Pattern 的步进格。步进格按吸附精度划分（关闭吸附时按 1/16），每拍深浅交替；音符起点格用实色，延音格更淡。
   - 一次显示 8 行，可在全部 64 个 Pad 行（A01–D16）之间滚动。
   - 保留实时播放头（高亮当前步）和标出触控区当前可见范围的框。
   - Sequence 模式的上屏不再显示 Project、Rev、Pads、Assets、MIDI 这一行。
2. **Pad 位置统一写作 `A01`。** 即 Bank 字母加两位编号。上屏行名、触控网格行名、Pad 矩阵都用这个格式；上屏行名只写编号，不写名称。
3. **同一个 Pad 在 Pad 矩阵、上屏行和触控网格音符中使用同一种颜色。** 颜色从哪来尚未决定，见 #1821。
4. **Sequence 页的旋钮分配。**
   - 旋钮 2（右上）滚动上屏的行，一格滚一行。滚动只移动上屏窗口，不切换当前 Bank。
   - 按 Bank 键 A–D 切换 Bank 时，上屏窗口跳到该 Bank 的第一行。
   - 旋钮 3 调 Tempo，一格 1 BPM；旋钮 4 调 Swing，一格 1%。录音中两者锁定，与现有的 Tempo、Swing 锁定规则一致。
   - 旋钮 1 暂不分配，见 #1822。
5. **Sequence 页的方向键。**
   - 不按 SHIFT 时，`←` `→` 切换到上一个、下一个 Pattern。播放中不能切换，与现有"先停止再切换 Pattern"的限制一致；不可用时指示灯熄灭。
   - SHIFT + `←` `→` 仍是撤销、重做，不变。
   - `↑` `↓` 暂不分配，见 #1822。
6. **触控区统一使用 D02 的视觉规范。**
   - 统一字体 IBM Plex Mono，标签为 10 px 大写灰字。
   - 控件统一为 44 px 高、8 px 圆角，底色 `#343a34`，选中时亮绿底深色字。
   - 卡片底色 `#202321`，10 px 圆角；间距只用 8 px 和 12 px。
   - 不使用浏览器原生的下拉框和勾选框。全局按钮样式不再影响机身内部。
7. **触控区分为 EDIT 和 SETUP 两层，默认显示 EDIT。**
   - 标题行用 `‹ GROOVE / NN ›` 加 `当前序号/总数` 切换当前 Pattern，取代 Pattern 下拉框；播放中不可切换。标题行右侧是 EDIT 和 SETUP 两个切换按钮。
   - EDIT 层：一行工具栏（吸附精度 1/4、1/8、1/16、1/32、关，加 NOTE / VEL 模式），其余空间全部给网格。网格的 16 行在一屏内完整显示，横向一屏显示一小节；框选后的删除、清除操作浮在网格右下角。
   - SETUP 层沿用 D02 的排版：
     - Tempo、Swing 两张卡片，可以拖推子，卡片上标明对应的旋钮（ENC 3、ENC 4）；
     - `BARS` 表示当前 Pattern 的长度；
     - Quantize 和节拍器做成两个开关；
     - 底部是 `+ NEW`（点了再选新 Pattern 的长度）、`COPY`、`TAP`。

## 原因

- D02 是桌面端唯一的布局与视觉依据，但 10-02 决策之后的实现偏离了它：
  - 上屏的 64 行缩略图每行约 1 px，看不清；
  - 触控区首屏被 Tempo、Swing 和 Bars 占满，网格要往下滚才能看到；
  - 一块屏上混用了三种字体、按钮和标签样式，还有浏览器原生控件。
- 8 行可滚动的上屏保留了"看到全部 64 行"的能力，同时每一行都清楚可读。
- 网格是 Sequence 页最常用手操作的部分，应该占满触控区；设定一次就很少再动的参数放进 SETUP 层。
- 连续调节的数值交给旋钮，切换 Pattern 交给方向键，触控区可以留给网格。
- `BARS` 在原实现里表示"新建 Pattern 的长度"，看起来却像当前 Pattern 的长度，会出现 Pattern 是 2 小节而 `BARS` 亮着 1 的情况。
