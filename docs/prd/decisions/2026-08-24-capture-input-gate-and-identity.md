# 已确认：采集静音缺口用「提交前电平门 + 输入身份可见」关闭，不引入设备选择器

- 日期：2026-08-24
- 结论：F4 采用选项 a + b 的组合。**a) 提交前输入电平门**：整段 take
  的峰值为数字静音（全零采样）时，Capture 面板拒绝提交并在面板内说明
  原因（采集到完全静音，可能是输入设备被系统静默切换）；take 不丢失，
  操作者可以重录或丢弃。门限只覆盖严格全零——低电平但非零的真实录音
  不受阻；更高的电平阈值需要物理数据支撑，留作后续调整。**b) 输入身份
  可见**：Capture 面板在 `recording` 与 `trimming` 阶段显示当前输入设备
  名（`MediaStreamTrack.label`；浏览器未给出标签时退化显示默认输入的
  占位文案），并在录制期间监听 `devicechange`，设备集合变化时在面板内
  给出非阻塞提示。**不**引入设备选择器：其缺失是 `1.0.23.0` 已声明的
  范围边界，本决策不扩大它。
- 原因：2026-08-17 物理会话（F4）证明 OS 默认输入被静默切换（macOS
  Continuity 改路由到 iPhone）时，`getUserMedia` 成功、流携带数字静音，
  Creator 会把 5 秒静音提交到 Pad 而毫无提示。电平门与设备无关地直接
  消灭「静音上 Pad」；身份可见让切换可察觉。两者都不引入选择器的权限
  /枚举/浏览器差异复杂度。
