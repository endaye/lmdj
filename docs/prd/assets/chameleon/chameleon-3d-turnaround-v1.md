# Chameleon 3D 造型三视图 v1

状态：`modeling-reference draft`

对应图片：[chameleon-3d-turnaround-v1.png](chameleon-3d-turnaround-v1.png)

## 用途边界

这张图是变色龙 AI 助手 / AI 宠物的 3D 造型参考，不是已经完成的 3D
模型、拓扑、绑定或可运行 Web 组件。建模师可以从中读取比例、主要体块和廓形，
但不能把生成图当作精确工程投影直接描模。

## 必须进入基础网格的识别体块

- 高而圆钝的头冠，与头骨保持连续体积；
- 两个可独立转动的眼球转塔，眼球与眼窝可分件；
- 楔形口鼻与稳定的嘴部平面；
- 短而柔和的背脊，不能做成纸片状尖刺；
- 紧凑的拱形躯干和可读的肩、肘、腕、髋、膝、踝体块；
- 四只对趾抓握脚，使用成对的厚实抓握瓣，不依赖贴图表达脚趾；
- 连续收细、无自交的可卷曲尾巴。

这些体块需要在无贴图、单色材质和纯黑廓形下仍能识别为变色龙。

## 建模复核

1. 用同一正交相机组输出正面、左侧和背面，不以三张独立模型对齐代替；
2. 三个视图的头高、眼球中心、肩线、髋线和尾根高度保持一致；
3. 正面和背面检查四肢左右对称，侧面允许为了廓形可读性轻微错开；
4. 尾巴默认顺时针卷曲，动画可以展开，但静止造型不得穿过躯干或四肢；
5. 头冠、背脊和眼球转塔先通过 24 px 廓形测试，再增加任何表面细节；
6. 鳞片、条纹、颜色分区、发光纹样和微表面全部留给可替换皮肤材质。

## 当前生成图的已知限制

- 三个视图是造型概念的一致性参考，不是数学意义上的同一网格正交投影；
- 手脚为了图形可读性做了简化，正式建模需要统一对趾数量和关节拓扑；
- 表情为中性注视；眨眼、眼球独立旋转和口部表情属于后续 rig 设计；
- 尾巴只定义默认卷曲姿态，尚未定义骨骼数量和动画约束。
