# 自然语言控制属于哪个用户、哪个 Stage？

- 范围：Stage 2–4
- GitHub Issue: #533
- 来源：[Needle 端侧小模型工具调用可行性验证](../../research/2026-09-01-needle-on-device-tool-calling-spike.md)
- 为什么重要：当前 Stage 的优先用户 DAW creator / Prosumer 恰恰最不需要自然语言——他们已知术语和快捷键。真正的候选是 Stage 3（Learn）与 Stage 4（Hardware），而两者需求几乎不重叠：前者是只读的意图导航，永不改 Project Truth；后者是会改状态的命令面。不先定就会把另一个做出来。
- 处理时点：Stage 3 或 Stage 4 立项之前。
