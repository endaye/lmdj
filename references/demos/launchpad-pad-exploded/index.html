    分层结构：每一层在做什么

    一块 pad 从手指到底壳大约只有 10–15 mm，却要同时解决四件事：把力可靠地传到传感器、 让 RGB 光均匀透出、在几十万次敲击后保持手感、以及让 16 或 64 个 pad 的灵敏度一致。 下面按爆炸图的顺序逐层说明。

    传感技术方案

    pad 的核心问题是把"敲了多重、按了多紧、按在哪"变成电信号。七类方案的横截面与取舍如下； 市售 pad 控制器绝大多数落在 A、B 两类电阻式方案里，MPE 类产品开始走向 E（电容）与 G（电感，Push 3）。

    信号链与速度算法

    速度（Velocity）

    • Δt 法：ADC 值先过低阈值 T₁、再过高阈值 T₂，Δt 越短速度越大。硬件要求最低，几乎所有电阻式 pad 都用它，再叠一条速度曲线（linear / log / exp）。
    • 斜率峰值法：在触发后 2–5 ms 窗口内取 d(ADC)/dt 的最大值。对轻敲更灵敏，但对采样率与噪声更敏感。
    • 峰值法（压电）：直接取脉冲峰值电压，需要峰值保持或高速 ADC。

    压力（Aftertouch / Poly AT）

    • Note On 之后持续读稳态 ADC，经一阶低通（fc ≈ 20–50 Hz）后映射成 0–127。
    • 电阻式方案的迟滞意味着"放松一点"比"按紧一点"反应慢，固件通常加下降补偿。
    • MPE 需要每 pad 独立 channel；X/Y 需要一个 pad 下有多个采样点（多区 FSR 或电容阵列）。

    工程要点（做一块好 pad 的清单）

    • 行程：0.6–1.5 mm。短行程手感像"按键"，长行程像"鼓"；行程越长速度分辨率越高。
    • 硅胶硬度：键垫级硅胶 Shore A 40–80 可选，pad 取偏软一端。太软 → 边缘敲击塌陷、串击；太硬 → 轻敲不出声。
    • 预压：装配夹紧力决定 pad 的"零点"，产线要做逐 pad 阈值校准并写入 EEPROM。
    • 加强板：PCB 弯曲 0.1 mm 就足以让 FSR 读数偏移，重型机把加强板与底壳合一。
    • 边缘敲击：胶粒做圆弧底面 + 框孔限位，避免"敲角上没反应"。
    • 匀光：硅胶加白色母粒、LED 居中、pad 下留 1–2 mm 混光腔；8×8 密排时侧发光 + 导光柱更均匀。
    • 扫描率：每 pad ≥1 kHz 才能让 Δt 法有 7 bit 以上速度分辨率；64 pad 常用多片 MUX 并行。
    • 串扰：相邻 pad 通过 keymat 与 PCB 传力，要在框体下加隔离肋并在固件里做邻 pad 抑制。
    • 寿命：电阻式 ≥100 万次；胶粒氧化是主要失效模式，电极镀金或印碳膜可延长寿命。
    • 可维修性：keymat 与传感薄膜做成独立备件（Akai pad sensor 即此思路）。

    与 LMDJ 的关系

    LMDJ Core 的 Pattern 事件引用 Pad Slot 而不是 Asset，正是为了让同一套演奏数据在不同硬件（4×4 厚垫、 8×8 薄垫、MPE 表面）之间可移植。本页梳理的"速度曲线、压力平滑、逐 pad 校准"都属于 Host / Provider 层要处理的 硬件差异，不应渗入 Project Truth。这个 demo 是理解这些差异来源的参考材料，不是产品代码。
