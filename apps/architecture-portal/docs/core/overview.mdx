## 八个产品中立 Module

<DiagramFrame title="LMDJ Headless Core" diagramId="lmdj-core" />

Foundation 提供基础类型；Authoring Domain 拥有 Project Truth；Project I/O 持久化并发布 portable Bundle；Project Cooker 生成不可变 Runtime Snapshot；Audio Runtime 消费快照；Provider SDK 隔离 Capability/Attempt；Application Facade 是 Host 唯一 Core 入口；Web Runtime Platform 为浏览器 Host 复用 Facade、输入、生命周期与 AudioWorklet 接线。

## 边界不变量

Hosts 不解析 Project Bundle；Bundle 是 transfer-only；Provider 不接收可变 Project；Product-specific wiring 只在 Product Assembly；Runtime Snapshot 永不反写成 Project Truth。

## 验证范围

模块单元/组件、Host parity、Provider conformance、Assembly Lock 与 Headless Proof 提供自动化证据；物理设备体验另行验收。
