## 1. 目的与非职责
准备样本、调度 Pattern/Pad 事件并离线或实时渲染；不修改 Project Truth。
## 2. 当前实现状态
Prepared Sample Bank、per-Pad published/preview playback、One-shot/Gate/Loop/Hold、stop/release、Voice state、Realtime Engine、Offline Renderer 与 WAV writer 已实现。实时渲染路径对 voice 触发施加恰好 96 帧（固定 48 kHz 下 2 ms）的线性 attack，对非循环 voice 在 `end_frame` 前最后 96 帧按 cursor 位置线性淡出，`stop_voice` 渲染 96 帧 release 尾音后停用（`stopped` 发布时机不变，仍在停止发起时发布；对 releasing voice 的再次停止或抢占立即停用且不二次发布）；循环回卷不重启 attack，全部斜坡状态为 Voice 的 POD 字段，实时路径保持无分配、无锁（F6 修复，Product Build `1.0.36.0` / audio-runtime `0.5.1`）；循环接缝 crossfade 按 2026-08-24 决策暂缓。
## 3. 所有权与依赖
依赖 Foundation 与 Project Cooker；平台输出位于适配边界。
## 4. 架构与数据流
Runtime Snapshot → Sample Bank 准备/发布 → fixed SPSC control 与 Voice-state 队列 → 音频线程 → 输出 sink；preview 只覆盖 Runtime，不进入 Project Truth。
## 5. API 与 Artifact 边界
消费不可变快照、resolved playback 与已准备样本，不在实时回调解析 Project/WAV、分配内存、加锁或调用 Host。
## 6. 状态、错误与并发
固定 SPSC 队列和压力测试覆盖 control/Voice 并发；overflow fail closed，实时路径避免无界工作。
## 7. 产品使用方
Native Host 与未来正式平台 Host 通过 Facade/适配层使用。
## 8. 测试与证据
Realtime、stress、offline、sample bank、queue 与 CoreAudio output 测试；物理延迟验收单列。
## 9. 限制与下一门禁
自动化绿色不证明 MIDI/iPad/扬声器体验；需保留设备视频和测量证据。
## 10. 版本身份
Module 版本由清单生成，Product Build 由 Assembly 固定。
