## 1. 目的与非职责
提供 Host 唯一 Core 入口并编排模块；不承载 Host UI、协议或产品特例。
## 2. 当前实现状态
Application Facade `1.4.4` 的 Application、Assembly Loader、C API、动态加载、streaming Project Bundle import/export，以及 typed Sample inspect/waveform/import/update/reset/retry surface 已实现；它保留受管存储恢复语义并依赖 Project I/O `0.6.1`。
## 3. 所有权与依赖
依赖全部六个下层 Module；Native/CLI/MCP Host 只依赖本 Facade，浏览器 Host 只依赖封装本 Facade 的 Web Runtime Platform。
## 4. 架构与数据流
Host 或 Web Runtime Platform 请求 → Facade → Domain/I/O/Cooker/Runtime/Provider SDK → typed response/stream result。Sample import token、cache 与 Project writer lease 均由 Facade/Core 拥有。
## 5. API 与 Contract 边界
C++ typed API 与严格 JSON/C API/MCP/CLI parity 保持跨 Host 边界；Bundle/Sample streaming API 不暴露 Project path 或 internals；Assembly Loader 校验锁定身份。
## 6. 状态、错误与并发
错误翻译保留公共类别；C API stress 验证并发生命周期。
## 7. 产品使用方
CLI、MCP、Native Test Host，以及通过 Web Runtime Platform 接入的 Creator/Diagnostic Web Host。
## 8. 测试与证据
Application、Sample session/atomicity/cache/privacy/replay、Bundle round trip/import cancellation、assembly loader、C API、stress 与 dynamic-load 测试。
## 9. 限制与下一门禁
Facade 不授权 Host 绕过 Project/Provider/Assembly 不变量。
## 10. 版本身份
版本和完整依赖集由模块清单与 Product Assembly 固定。
