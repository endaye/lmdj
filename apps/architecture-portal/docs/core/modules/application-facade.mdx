## 1. 目的与非职责
提供 Host 唯一 Core 入口并编排模块；不承载 Host UI、协议或产品特例。
## 2. 当前实现状态
Application、Assembly Loader、C API 和动态加载已实现。
## 3. 所有权与依赖
依赖全部六个下层 Module；Host 只能依赖本 Facade。
## 4. 架构与数据流
Host 请求 → Facade → Domain/I/O/Cooker/Runtime/Provider SDK → typed response。
## 5. API 与 Contract 边界
C++/C API 保持跨 Host 边界；Assembly Loader 校验锁定身份。
## 6. 状态、错误与并发
错误翻译保留公共类别；C API stress 验证并发生命周期。
## 7. 产品使用方
CLI、MCP、Native Test Host 与 Formal Web Runtime Host。
## 8. 测试与证据
Application、assembly loader、C API、stress 与 dynamic-load 测试。
## 9. 限制与下一门禁
Facade 不授权 Host 绕过 Project/Provider/Assembly 不变量。
## 10. 版本身份
版本和完整依赖集由模块清单与 Product Assembly 固定。
