## 1. 目的与非职责
事务式保存/加载 Project Truth 并维护 Take Journal；不 Cook 或渲染。
## 2. 当前实现状态
Project Store、Journal 和故障注入路径已实现。
## 3. 所有权与依赖
依赖 Foundation 与 Authoring Domain；平台适配不能改变领域语义。
## 4. 架构与数据流
Facade 提交 Project，Store 写入临时状态并原子发布，Journal 记录 Take 边界。
## 5. API 与 Artifact 边界
只持久化 Project Truth；Runtime Snapshot 明确禁止持久化为创作真相。
## 6. 状态、错误与生命周期
故障矩阵验证中断恢复；typed error 区分输入、平台与提交失败。
## 7. 产品使用方
Application Facade 使用；Host 不直接解析 bundle。
## 8. 测试与证据
Project store、Take journal、fault matrix 与 storage platform contract 测试。
## 9. 限制与下一门禁
云同步和协同冲突策略未批准，不能从本地存储能力推断。
## 10. 版本身份
版本和依赖由 `module.json`/Assembly Lock 派生。
