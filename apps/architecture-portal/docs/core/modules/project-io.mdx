## 1. 目的与非职责
事务式保存/加载 Project Truth、导入/导出 portable Project Bundle，并维护 Sequence journal overlay、flush receipt 与 recovery artifact；不 Cook、渲染或拥有 Host UI。
## 2. 当前实现状态
Project I/O `1.0.0` 的 Store、Sequence Journal、streaming Bundle parser/packer、v1/v2 读取与 v3-only 写出、Workspace Cache 和 crash-safe publication 已实现。flush 以 manifest replacement 为 commit point，并把 command/session/flush identity 与 committed revision 写入可幂等重放的 receipt。当前 source 在每个已接受 Sequence Pad event acknowledgement 前 append 单调、checksummed canonical tail；flush record 消费同一 tail。若较早 flush 在 commit point 前失败，后续 flush 必须 canonical 覆盖全部 unresolved batch 与最新 tail；后续 receipt 可见时同步 resolve 被覆盖的 flush，owner loss 因而只 seal 真正未提交部分。所有普通 authoring mutation 仍在持有 writer lease 后重读 active Sequence Journal；存在 active journal 时只有 `UpdateSequenceSettings` 属于既有白名单，其成功提交由 Store 同步 rebase journal。
## 3. 所有权与依赖
依赖 Foundation 与 Authoring Domain；平台适配不能改变领域语义。
## 4. 架构与数据流
Facade 提交 Project、Bundle stream、bounded Sample bytes 或 Sequence flush；Project I/O 在 writer lease 下验证 journal overlay 和 authoring admission，原子发布 Project v3 revision，再完成 receipt。Store 只暴露已提交 Project Truth；未提交 overlay、owner-loss recovery artifact、waveform cache 与不可变 Runtime Snapshot 生命周期彼此独立。active journal 的拒绝错误携带 session identity 和 stop-or-reconcile remedy，不允许调用者从无锁内存观察推断 authority。
## 5. API 与 Artifact 边界
只持久化 Project Truth 与原始 WAV Artifact；`lmdj.project-bundle.v1` 只定义 transfer envelope；Workspace waveform cache 可丢弃重建，Runtime Snapshot 明确禁止持久化为创作真相。
## 6. 状态、错误与生命周期
故障矩阵验证验证、取消、超时与发布中断恢复；typed error 区分输入、平台、busy 与提交失败。
## 7. 产品使用方
Application Facade 使用；Host 不直接解析 bundle。
## 8. 测试与证据
Project store、v1/v2→v3 migration、atomic Sample transaction、Sequence journal/receipt/recovery、durable tail reload/flush consumption、失败 F1 被成功累积 F2 exactly-once supersede、torn/checksum/sequence/canonical corruption 的统一 fail-closed evidence、writer-lease 内 direct-authoring refusal/settings rebase、Bundle 1.0/1.1 round trip/publication、fault matrix、distinct-platform publication ownership、Native link-count 与 Web/native storage platform contract 测试。
## 9. 限制与下一门禁
云同步和协同冲突策略未批准，不能从本地存储能力推断。
## 10. 版本身份
版本和依赖由 `module.json`/Assembly Lock 派生。
