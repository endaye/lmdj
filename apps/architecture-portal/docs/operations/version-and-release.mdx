## 四条版本轴
Product Build 使用四段式；Core Module、Host 与 Provider 使用独立 SemVer；Contract 使用稳定 ID + Contract SemVer。
## Assembly Lock
锁文件记录确切组件版本与 source hash，门户同样从它生成身份，防止文档手填漂移。
当前本地候选 Product Build 是 `1.0.15.2 · canary · g<short-sha>`；Web Runtime Host `1.1.2` 已进入 Assembly 和生成 lock。除此之外 Module/Host identity 均未变化；Contracts、Providers 与 Models 未变化。
## Git 与发布
Task commit、push、PR、squash merge、signed product tag、Release、部署和 Channel promotion 是不同授权与证据。
## 不可变性
已发布 tag 不移动；交付测试或正式发布的文档快照按 Product Build 冻结，current 文档持续跟随 main。普通 PR Preview 不创建永久快照。
schema-2 快照冻结 34 页源码、sidebar、九张图的 18 个 HTML/SVG 资产、源提交与 source projection；后续 current 或 diagram 变化不能改写已冻结版本。生成前允许的脏路径仅限该 Product Build 的精确生成边界，提交后还必须验证 introducing commit、时间顺序以及 direct-parent 或获准的 squash-equivalent projection。
## 发布门禁
实现计划必须声明 Version impact；测试发布和 stable release 前都验证匹配的说明书快照，再分别运行该 Channel 所需的版本验证、测试、CI、产品验收与发布证据门禁。

本地已存在 signed annotated Product tag `lmdj-v1.0.15.2`：`git tag -v` 的 Good signature
primary fingerprint 是 `2B5EE362F058800036AD4FB5116ECE156F954D29`，target 是
`72ae40074620cc5681c462ba04a31a666449734f`。该 tag 尚未 push，未做远端验证；因此当前
Task 不宣称远端 CI、merge、Release、部署、发布或 Channel promotion。匹配 Product Build
的不可变快照与 provenance 由 `versions.json`、冻结 metadata 和 Portal 校验器共同判定；
current 页面不按 Task 顺序声明其临时存在状态。历史 `1.0.14.0` 的 PR #91 与 merged-main

## Runtime Host 公共发布

Runtime Host 的两阶段发布工具和 workflow 定义已经存在：先从精确 signed Product tag
与 Release archive 验证身份，创建 immutable Netlify draft，对 draft 运行 HTTP 与
Chromium smoke，再只把同一个 ready Deploy ID 发布到
`https://lmdj-runtime.netlify.app`，最后写出 evidence artifact。它是实现好的操作路径，
不是当前已发生的发布。

当前 `1.0.15.2` / Host `1.1.2` 仍为 pre-deploy：没有 push、PR review、CI、merge、
远端 verified tag、Release、`lmdj-runtime` Netlify project、GitHub Environment secret、
workflow run、Deploy ID、immutable URL、production alias 或 deployment evidence。只有
实际 evidence record 才能让 Portal 报告公共部署；本地工具、Proof、PR Preview 或
workflow 定义都不能替代它。运营前置条件、回滚和凭据轮换见仓库运行手册
`docs/deploy/web-runtime-host.md`；其验收真相记录见
`docs/quality/2026-08-08-web-runtime-public-deployment-acceptance.md`。

proof-only Python server 不属于生产面；Netlify 将静态服务经验证的 release `dist`。
`lmdj-canary` 保留给未来 Creator，不能作为本 Runtime Host Task 的项目、别名或 URL。
