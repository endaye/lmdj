## Host 规则

Native/CLI/MCP Host 只通过 Application Facade 调用 Core；浏览器 Host 只通过共享 Web Runtime Platform 间接使用 Facade。任何 Host 都不解析 Project Bundle，也不把协议/UI 逻辑下沉到 Core。

## 当前清单

CLI `1.0.7`、MCP `1.1.4`、Native Test Host `1.0.5`、Formal Web Runtime Host `1.2.1` 与 Creator Web Host `1.0.1` 已锁入 Product Build `1.0.16.1` Assembly。两个 Web Host 只依赖共享 Web Runtime Platform `0.1.1`；Web Runtime Lab 仍是独立实验工具，不是正式 Host。

## 生命周期

每个 Host 负责进程/设备输入输出、调用取消和结果呈现；Core typed error 不应被抹成无结构文本。

## 下一门禁

Creator clean-source packaged Proof 与五条物理设备验收分别记录；后者仍为 `deferred / unverified`，并继续阻断 physical-pass、`beta` 和 `stable` 声明。
