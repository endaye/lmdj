## 状态

<StatusBadge status="partial" /> 正式 Host 的 source shell、64-Pad 输入归一化、显式音频/MIDI 激活、生命周期状态机与隐私诊断已进入 active source；它仍未出现在 Product Assembly 或 Assembly Lock，Task 12 才拥有该成员关系。

## 目标边界

Main thread 只负责 preflight、manifest/hash 装载门、用户手势、DOM/MIDI 输入、生命周期观察、有界 transport 与终止清理；Project、OPFS、Facade、解码与混音仍由 Control/Core 边界负责。Pointer、Keyboard、MIDI 汇入唯一 `trigger(flatSlot, velocity)` 路由。

## 生命周期门禁

普通 Trigger 与全部 `take.begin` 只在 `running` 接收。中断同步关闭 admission、清除 pressed state，并按 epoch 只发一次 Control suspend/seal。恢复必须同时具备 Context `running`、正整数 current/ack generation 相等，以及一个真实用户 recovery probe 的唯一 `voice_started`；visibility 或 pageshow 本身不能完成恢复。

## 自动化证据

Node source-shell 行为回归与隔离测试源上的 Chromium lifecycle spec 已覆盖静态壳、激活、中断、probe、超时、协议失败、隐私 allowlist 和 once-only cleanup。这些自动化不等于 packaged Wasm/OPFS/Worklet 全链路，也不等于物理 Touch-to-Sound。

## 非能力

当前不能宣称 Host 已 Assembly-listed、正式 Web 产品已交付、真实 packaged journey 已通过，或 MIDI/iPad/延迟体验已完成物理验收。
