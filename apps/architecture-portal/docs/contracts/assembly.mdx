## 目的
`lmdj.assembly.v2` 声明一个 Product Build 允许的 Module、Host、Provider、Contract 与 Provider policy。
## Source 与 Lock
`assembly.json` 是声明，`assembly.lock.json` 固定解析后的版本和 source hash；两者不匹配时构建失败。
## 产品边界
产品专属 wiring 只存在于 `products/lmdj`，不能泄漏到产品中立 Module。
## 交付证据
Application Facade 装载并校验 Assembly；版本/lock conformance 测试覆盖一致性。
