## 权威内容
`lmdj.project.v1` 表达可编辑的 Project Truth：素材引用、Pad Slot、Pattern 和创作结构。
## 明确排除
Runtime Snapshot、Provider 选择、Attempt failure、设备句柄和 Host 偏好不属于 Project Truth。
## 引用不变量
Pattern event 引用 Pad Slot，Slot 再关联 Asset；事件不直接绑定 Asset。
## 使用方与证据
Authoring Domain、Project I/O 与 Cooker 消费该 Contract，并由领域/I/O/Cooker 测试验证。
