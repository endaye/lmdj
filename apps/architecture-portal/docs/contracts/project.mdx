## 权威内容
`lmdj.project.v3 · 3.0.0` 是唯一当前写入真相：表达素材引用、Pad Slot、完整 per-Pad playback、BPM、`quantize_enabled`、`swing_percent`，以及 tick-native PPQ 960 Pattern events。Project I/O 可读取 v1/v2，并在第一次成功 mutation 前完成确定性总迁移；writer 永远只发出 v3。
## 明确排除
Runtime Snapshot、Provider 选择、Attempt failure、设备句柄和 Host 偏好不属于 Project Truth。
## 引用不变量
Pattern event 引用 Pad Slot，Slot 再关联 Asset；事件不直接绑定 Asset。playback 属于 Slot，不属于不可变 Asset，同一 WAV 可被多个 Slot 以不同参数引用。
## 使用方与证据
Authoring Domain、Project I/O、Cooker 与 Facade 消费该 Contract，并由 schema、领域、v1/v2→v3 migration、Cook、headless 与 packaged browser Proof 验证。录音过程本身是 journal overlay；只有 flush 的 commit receipt 对应 revision 发布后，Pattern events 才进入 Project Truth。
