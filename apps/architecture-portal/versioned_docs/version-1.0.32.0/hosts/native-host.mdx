## 目的
正式的无界面 Native Host（binary `lmdj-native-host`）：从真实 `.lmdj` Project 经 Application Facade 进入应用/控制面，并直接使用 Audio Runtime 实时数据面做本机播放、capture 与设备验证；不承担产品 UI。它随每个分发包发出，分发成员资格受 `docs/governance/distribution-contents.md` 约束。该 Host 在 Product Build `1.0.31.0` 由 `native-test-host`（止于 `1.0.14`）改名而来；二进制名、协议与测试面不变。
## 数据流
请求 → Application Facade/Audio Runtime → capture writer/设备输出 → 可保留证据。
## 生命周期
Host 管理设备开启、停止和 capture 文件；实时引擎所有权仍在 Audio Runtime。
## 测试与证据
Native host 测试验证协议与输出；物理听感和端到端延迟单独验收。
## 限制
它是薄 Host，不应扩展为隐藏的产品专属 Core。
