## 创作能力

Project Truth、命令处理、项目存取、portable Bundle transfer 与确定性 Cook 已实现于 Headless Core；Creator Web 已提供 Project discovery/open、portable import、64-Pad Runtime surface，以及 Sample inspect/waveform、WAV import/replace、trim/gain/mute、四种触发模式、preview、reset、麦克风 Pad Capture、pre-commit Crop 与 Cook retry。Crop 只修改未提交 capture，不是持久化 Asset 编辑；多素材浏览、自动 slicing、Undo、非破坏音频处理和 Sequence 编排仍待后续 Stage。

## 演奏能力

Runtime Snapshot、样本准备、离线渲染、实时引擎、Voice 状态与 Sample preview 具有自动化覆盖。低延迟手感、MIDI/触控输入和设备生命周期需要独立物理验收。

## 智能能力

Capability Contract、Registry、Attempt Store 与本地成功/失败 Proof Provider 已实现。生产模型、云服务、鉴权、计费和数据政策尚未实现。

## Host 与交付能力

当前 source 已为 Product Build `1.0.32.0` 组合 Creator Capture UI F1–F5 与实时渲染 F6：Creator Web Host `1.5.4` 与 Formal Web Runtime Host `1.2.14` 已装配，并共用 Web Runtime Platform `0.3.5`。Creator 提供模态 Capture 面板、焦点迁移、trim 握把、可恢复 `DUPLICATE_ID`、提交前静音门与输入身份；Audio Runtime `0.5.1` 提供恰好 96 帧（固定 48 kHz 下 2 ms）的线性 attack/release 斜坡。按 Core Module 级联，Application Facade 升至 `1.4.5`、CLI 升至 `1.0.17`、MCP 升至 `1.1.14`、Native Host 升至 `1.0.1`；Project I/O `0.6.1`、Provider 与 Contract 身份不变，循环接缝 crossfade 按 2026-08-24 决策暂缓。Product Build `1.0.31.0` 曾将 `native-test-host` 改名为 Native Host 并确立分发包内容准则；`1.0.30.0` 曾分配 Creator `1.4.0` 的 pre-commit Crop；Product Build `1.0.29.0` 曾分配 Creator `1.3.6` 的选区波形缩放修正。
Product Build `1.0.25.0` 曾分配 G2 evidence-durability 级联，同样不新增公开产品能力。
Product Build `1.0.24.0` 曾分配 provider-sdk 修复级联：CLI `1.0.13`、MCP `1.1.10` 与 Native Test Host `1.0.11` 已装配；Creator Web Host `1.3.1` 与 Formal Web Runtime Host `1.2.10` 已装配，并共用 Web Runtime Platform `0.3.1`；本地成功/失败 Proof Provider 也同步升至 `1.0.3`。那次分配修复的是 Attempt reservation 回收与 temp sibling 命名冲突，不新增公开产品能力。

Web Runtime Lab 保持为独立实验工具，不属于 Product Assembly，也不替代正式 Host 或物理设备验收。Product Assembly 锁定确切组件身份，版本发布不由任意 Host 决定。
