## 音频边界

输入为 little-endian PCM16 RIFF/WAVE，mono/stereo，44.1 或 48 kHz，至少一个完整
frame。解析遵循 chunk 长度与奇数字节 padding，验证 RIFF 边界、block alignment、
byte rate 及唯一 fmt/data chunk；不假定固定 44-byte header。未知且完整的 chunk
可跳过，截断、重复 chunk、浮点、压缩、extensible 与 RF64 格式拒绝。

SDK 先验证 Artifact 绑定、hash、长度与访问权限；消费方负责解码与 profile 校验。
Provider 只获得已绑定字节和 output sink，不获得 Project、bundle 或 Workspace 路径。
