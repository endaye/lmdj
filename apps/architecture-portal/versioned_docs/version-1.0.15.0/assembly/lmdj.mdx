## 当前组合
当前本地候选 Product Build `1.0.15.0` 的 LMDJ Assembly 组合七个 Core Module、四个 Host、两个本地 Proof Provider与六个 active Contract。`web-runtime-host` 更新为 `1.1.0`；Project I/O `0.4.0`、Audio Runtime `0.4.0`、Application Facade `1.2.0`、CLI `1.0.5`、MCP `1.1.2`、Native Test Host `1.0.3` 与 Project Cooker `0.2.1` 均保持不变。
## 编译接线
`products/lmdj/src/compiled_assembly.cpp` 是产品专属 wiring；产品中立模块不知道 LMDJ 的具体组合。
Product CMake 只在 Emscripten `lmdj_web_runtime_host` target 存在时链接 compiled catalog object，保留 Native 与 Web 配置的源边界。Web Host 只声明 Facade/Audio 依赖，不直接依赖 Project I/O；Provider wiring 仍只属于 Product Assembly。
## Policy
当前 Provider policy 仅允许 local/public/proof.execute 范围，与 Proof-only Provider 相符。
## 身份与完整性
Product Build、每个组件版本和 source hash 被锁定；门户事实生成会拒绝任何漂移。
Contracts、Provider、Capability 与 model identity 均未变化；同构建 Web transport 没有创建公开 Contract。
## 限制
Creator GUI、生产 Provider、云能力、物理 Web 验收与 `beta`/`stable` 均不能由当前 Assembly 成员关系或门户快照推导。Build Identity 只证明当前页面绑定的 Product/Assembly 身份。
