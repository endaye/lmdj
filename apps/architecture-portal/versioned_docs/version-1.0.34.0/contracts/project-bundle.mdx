## 权威内容

`lmdj.project-bundle.v1` 是 portable Project transfer envelope：canonical index 固定 Project ID、Project Contract、entry path/offset/bytes/SHA-256、总字节数和整个 Bundle digest；当前版本只允许无压缩 payload。

## 与 Project Truth 的关系

Bundle 只负责传输，不是新的创作真相。成功导入后，`lmdj.project.v1` 仍是权威 Project Truth；Runtime Snapshot、Provider/Attempt、Workspace/Host setting 与设备状态不进入 Bundle。

## 安全与发布

解析器对 header、索引、路径、大小、重叠、顺序、重复、hash 与 Project identity fail closed。导入先完整验证并 staged，随后由 Project I/O journal 原子发布；失败、取消或超时不得留下可打开的半成品 Project。

## 使用方与证据

Application Facade 暴露 streaming import/export；Creator Host 只传递字节和展示 typed result。Schema、parser、round trip、故障注入、取消与 OPFS publication tests 固定该边界。
