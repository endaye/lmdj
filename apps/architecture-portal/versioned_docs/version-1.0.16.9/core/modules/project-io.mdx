## 1. 目的与非职责
事务式保存/加载 Project Truth、导入/导出 portable Project Bundle 并维护 Take Journal；不 Cook、渲染或拥有 Host UI。
## 2. 当前实现状态
Project Store、Journal、streaming Bundle parser/packer 与 crash-safe publication 已实现。
## 3. 所有权与依赖
依赖 Foundation 与 Authoring Domain；平台适配不能改变领域语义。
## 4. 架构与数据流
Facade 提交 Project 或 Bundle stream；Project I/O 先完整验证并 staged，再 journal publish，Store 只暴露已提交 Project；Take Journal 独立记录演奏边界。
## 5. API 与 Artifact 边界
只持久化 Project Truth；`lmdj.project-bundle.v1` 只定义 transfer envelope；Runtime Snapshot 明确禁止持久化为创作真相。
## 6. 状态、错误与生命周期
故障矩阵验证验证、取消、超时与发布中断恢复；typed error 区分输入、平台、busy 与提交失败。
## 7. 产品使用方
Application Facade 使用；Host 不直接解析 bundle。
## 8. 测试与证据
Project store、Bundle parser/round trip/publication、Take journal、fault matrix 与 storage platform contract 测试。
## 9. 限制与下一门禁
云同步和协同冲突策略未批准，不能从本地存储能力推断。
## 10. 版本身份
版本和依赖由 `module.json`/Assembly Lock 派生。
