## 目的
Core MCP `2.0.0` 通过 MCP stdio 暴露受控 Core 工具，包括 Pattern create、Sequence recording/settings/recovery，使长生命周期 owner 与 CLI 保持 Facade parity。
## 协议边界
Host 管理 initialize、工具 schema、structured content 与 JSON-RPC 错误；业务语义仍来自 Facade。
## 安全与状态
输入按请求验证，Host 不持久化 Runtime Snapshot 为 Project Truth。
## 测试与证据
stdio 与 Facade parity 测试覆盖工具形状、字节协议和错误映射。
## 限制
MCP 可用性不代表产品 UI 或远程多租户服务已交付。
