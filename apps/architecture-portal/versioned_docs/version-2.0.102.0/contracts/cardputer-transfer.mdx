## 有界内容传输

`lmdj.cardputer-transfer.v1 · 1.0.0` defines the semantic projection for the
Cardputer USB framing. It carries version, opcode, request ID, session nonce,
and bounded payload bytes. The wire encoding and conformance vectors remain in
the contract directory; this Contract is not Project Truth and does not grant
sender authentication.

Malformed, stale-session, out-of-order, over-limit, and incomplete transfers
must fail closed; only complete identity-verified content may reach the Core
load boundary.
