## Active Contract 集
Product Assembly 固定 Project、Capability v2、Assembly v2、Error、Module Manifest 与 Product Version 六个 Contract。
## 版本规则
Contract ID 表示稳定边界，Contract SemVer 表示该边界自身版本；Product Build 与 Contract 版本不是同一轴。
## 运行态边界
Runtime Snapshot 是从 Project 派生的内部不可变边界，目前不作为单独持久化 Contract。
## 兼容性
新增代码只使用 Assembly Lock 中 active Contract；历史 Contract 只在 History 页面解释。
