## 目的
提供脚本友好的命令行入口，经 Application Facade 执行项目、Cook、渲染与 Proof 操作。
## 边界
CLI 负责参数/JSONL/退出码，不直接访问下层 Module 或重写公共错误。
## 数据流
stdin/参数 → CLI adapter → Facade → 规范 JSON/Artifact 输出。
## 测试与证据
`tests/host/cli_test.py` 覆盖协议、错误和快照输出；版本来自 Host manifest。
## 限制
CLI 是工程 Host，不等同于最终创作者 GUI。
