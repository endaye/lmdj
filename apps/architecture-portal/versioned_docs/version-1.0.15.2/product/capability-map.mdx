## 创作能力

Project Truth、命令处理、项目存取与确定性 Cook 已实现于 Headless Core；面向最终用户的素材浏览、Pad 编辑和编排界面仍属于产品 UI 范围。

## 演奏能力

Runtime Snapshot、样本准备、离线渲染与实时引擎具有自动化覆盖。低延迟手感、MIDI/触控输入和设备生命周期需要独立物理验收。

## 智能能力

Capability Contract、Registry、Attempt Store 与本地成功/失败 Proof Provider 已实现。生产模型、云服务、鉴权、计费和数据政策尚未实现。

## Host 与交付能力

CLI、MCP、Native Test Host 与 Formal Web Runtime Host `1.1.2` 已装配；Formal Host 已通过自动化 clean-distribution Web Proof。Web Runtime Lab 保持为独立实验工具，不属于 Product Assembly，也不替代 Formal Host 或物理设备验收。Product Assembly 锁定确切组件身份，版本发布不由任意 Host 决定。
