## Host 规则

Native/CLI/MCP Host 只通过 Application Facade 调用 Core；浏览器 Host 只通过共享 Web Runtime Platform 间接使用 Facade。任何 Host 都不解析 Project Bundle，也不把协议/UI 逻辑下沉到 Core。

## 当前清单

CLI、MCP 与 Native Host 为 `3.2.0`，Formal Web Runtime Host 与 Creator Web Host 为 `4.1.0`，一起锁入 Product Build `1.0.45.0` Assembly。五个 Host 只经 Application Facade `3.2.0`（Web Host 经 Platform `4.1.0`）使用 Project v4、共享 Sample quota、Sequence recording 与本 Build 新增的 Sound Set 目录浏览、检查、映射预览与安装；Web Hosts 把长选区拆成有界 chunk 并在浏览器侧取回 Catalog 字节交给 Core 暂存，Native/Web 输入共享 Audio Runtime `3.0.0` frame clock，Host 不解析 Project bundles 或复制 quantizer。
Product Build `1.0.25.0` 的 G2 evidence-durability 级联锁定 CLI `1.0.14`、MCP `1.1.11`、Native Test Host `1.0.12`、Formal Web Runtime Host `1.2.11` 与 Creator Web Host `1.3.2`。
CLI `1.0.13`、MCP `1.1.10`、Native Test Host `1.0.11`、Formal Web Runtime Host `1.2.10` 与 Creator Web Host `1.3.1` 已锁入 Product Build `1.0.24.0` Assembly。CLI/MCP/Native 通过 Facade 获得 Sample parity；两个 Web Host 只依赖共享 Web Runtime Platform `0.3.1`；Web Runtime Lab 仍是独立实验工具，不是正式 Host。

## 生命周期

每个 Host 负责进程/设备输入输出、调用取消和结果呈现；Core typed error 不应被抹成无结构文本。
