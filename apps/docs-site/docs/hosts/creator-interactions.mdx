## 1. 整机与全局规则 \{#global\}

### 1.1 控制台四区 \{#console\}

<ConsoleDiagram />

- **左栏**：Logo（即 System 入口）、2×2 的 ENC1–ENC4，以及八行按键：Project｜Sample、Sequence｜Perform、A｜B、C｜D、↑｜↓、←｜→、SHIFT（占一整行）、Record ●｜Play/Stop ▶。[布局参考](https://github.com/endaye/lmdj/blob/main/docs/design/2026-09-11-lmdj-hardware-ui-layout-reference.md)第 4 节的 −／+ 行目前不存在，方向键上移，SHIFT 占第 7 行。
- **上屏**：只读反馈区。它没有可点击的音乐按钮、旋钮、波形拖拽点或网格编辑点。编辑都来自左栏、Pad 和触摸区。
- **16 个 Pad**：当前 Bank 的 16 个声音槽，地址见 [1.8](#pads)。
- **触摸区**：内容随当前页面变化，各页分别说明。

### 1.2 页面键与 System 入口 \{#pages\}

按任一页面键都会关闭 System、清除 SHIFT 和未松开的按压。普通换页不停止全局 Pattern 播放或录音。

| 按键 | 可用条件 | 结果 |
| --- | --- | --- |
| Project | 任意时候 | 进入 Project。 |
| Sample | 任意时候 | 进入 Sample。普通重新进入时显示 Trim 子页。 |
| Sequence | Project 已打开且支持 Sequence | 进入 Sequence，默认显示 EDIT。 |
| Perform | Project 已打开 | 进入 Perform。缺少音频或录音存储时，触摸区说明还在等待什么。 |
| 从 Perform 换到其他页 | 任意时候 | 先结束 Perform 的演出录制和 Replay，再换页。已停止、待保存的演出保留。 |
| Logo（System） | 任意时候 | 打开 System，见[第 8 章](#system)。 |

没有打开的 Project 时，上屏显示 NO PROJECT，Sequence 与 Perform 键不可用。

### 1.3 播放与录音：Play/Stop 与 Record \{#transport\}

左栏 Play/Stop 和 Record 在**每一页**都只控制全局 Pattern，不会变成采样或演出录音。

| 状态 | Play 灯 | Record 灯 | 此时的限制 |
| --- | --- | --- | --- |
| 停止 | 灭 | 灭 | 只有此时能切 Pattern、改 Pattern 长度和结构。 |
| 播放 | 亮 | 灭 | 可以打 Pad，可以改 Tempo／Swing；不能切 Pattern 或改长度。 |
| 录音 | 亮 | 亮 | Pad 事件录入当前 Pattern；Sequence 网格编辑、Tempo／Swing／Quantize 和 Pad 改色不可用。 |
| 命令处理中 | 等结果 | 等结果 | Play/Stop、Record 和相关设置暂不可用；以灯的最终状态为准。 |

| 当前状态 | 按键 | 结果 |
| --- | --- | --- |
| 停止 | Play/Stop | 当前 Pattern 开始循环播放；需要时先唤醒音频。不改作者内容。 |
| 播放 | Play/Stop | 停止 Pattern。不会关闭整个音频引擎；手打 Pad 仍按各自的触发模式发声。 |
| 录音 | Play/Stop | 停止播放并保存本轮录入的事件；保存后网格显示这些事件。失败时保留提示和恢复入口。 |
| 停止 | Record | 同时开始播放和录音。 |
| 播放 | Record | 从当前位置开始叠录，不从头重新播放。 |
| 录音 | Record | 结束录音并保存事件，Pattern 继续播放。 |
| 没有 Project、音频未就绪、命令处理中或另一种录音进行中 | 任一键 | 按键不可用。Play 与 Record 的条件不完全相同，见[附录 A.2](#conditions)。 |

- 录音中屏幕上即时出现的事件还没有保存；结束录音才保存。
- 按 Play/Stop 或 Record 会清除 SHIFT。

### 1.4 三种录音 \{#recordings\}

| 入口 | 录什么 | 怎样保存 |
| --- | --- | --- |
| 左栏 Record ● | Pad 事件，录进当前 Pattern | 再按 Record 或按 Play/Stop 时保存。 |
| 按住空 Pad（任意页） | 一段音频，录进这个 Pad；来源在 System 选麦克风或内部播放 | 正常松手后自动尝试保存，见 [1.9](#pad-capture)。 |
| Sample 的 Record Sample | 麦克风音频，录进所选 Pad | Stop 后必须按 Commit，见 [4.7](#capture)。 |
| Perform 的 Record Performance | 演出操作和主输出 WAV | Stop 后在 Takes 按 Save，见[第 6 章](#perform)。 |

一种录音进行中时，其他录音入口不可用或不会开始。

### 1.5 Bank 键与当前 Pad \{#bank\}

Bank A／B／C／D 把下边 16 个 Pad 换成该 Bank 的 A01–A16／B01–B16／C01–C16／D01–D16。

- Bank 键不改 Pad 内容、Pattern 或作者内容。
- Bank 键会清除 SHIFT、未松开的按压，以及 Sequence 中点 Bank 前的音符选区。
- Pattern 播放或录音时也能切 Bank。
- Project 未就绪、Runtime 未就绪或文件正在传输时，Bank 键仍显示，但不会切换。

“当前 Pad”在不同页面含义不同：

- **Sample**：所选 Pad，显示白边加绿点。按已分配的 Pad 会选中它，换 Bank 保留本 Bank 内序号（A03 → B03）。
- **Sequence**：用 ↑↓ 移动的当前 Pad（A01–D16）。打 Pad 只演奏，不移动当前 Pad。
- **Project／Sound Sets／Slice**：打 Pad 时 Sample 的所选 Pad 也跟着变，进入 Sample 后可以看到。

### 1.6 SHIFT 与 Undo/Redo \{#history\}

- SHIFT 是点一下开、再点一下关的锁存键。它本身不改任何内容。
- SHIFT 打开时，← 是 Undo，→ 是 Redo，每次撤销或重做一次作者编辑。
- ← → 的灯在有可撤销或可重做的编辑时亮。灯亮不代表不开 SHIFT 也能按。
- SHIFT 关闭时，← → 在 Sequence 切 Pattern，在其他页不可用。
- SHIFT 在换页、换 Bank、按 Play/Stop 或 Record、完成一次 Undo/Redo 后自动关闭。
- Undo/Redo 恢复的是已保存的作者内容，例如 Pad 分配和颜色；它不撤销播放、下载或导出。
- Undo/Redo 会清除 Sample 中未完成的参数草稿，并刷新各页显示。
- 没有历史、采样或演出待处理、参数草稿未完成或正在保存时，Undo/Redo 不可用。不能用 Undo 绕过未完成的操作。
- Undo/Redo 执行期间，整个控制台暂时不接受操作。
- SHIFT 不会给旋钮增加粗调。

### 1.7 旋钮与方向键 \{#encoders\}

- 旋钮用滚轮、上下拖动，或聚焦后按方向键转动。向上、向右是增加，向下、向左是减少。
- 单击旋钮没有额外动作。
- **目前只有 Sequence 页绑定了 ENC1–ENC4 和 ↑↓**；其他页这些控件不可用。具体作用见[第 5 章](#sequence)。
- ← → 不按 SHIFT 时只在 Sequence 切 Pattern；按 SHIFT 时在所有页面做 Undo/Redo。
- 调数值的旋钮（Sequence 的 Tempo、Swing）转动时立即预览，停转 400 ms 后保存一次。转回起点不保存。
- 录音中或命令处理中，这两个旋钮不可用，正在预览的值作废。
- 还没保存的旋钮预览，在换页、打开 System、换 Project 或换 Pattern 时作废；下次转动从已保存的值开始。

### 1.8 16 个 Pad：地址、键盘与 MIDI \{#pads\}

四个 Bank 共 64 个声音槽，每次显示 16 个。每个格子的行为相同，只是目标槽不同。

屏幕按 MPC 方向排列：左下是 01，向右到 04，再向上逐行增加。Tab 焦点按屏幕从上到下、从左到右访问可用的 Pad。Sound Set 安装预览也用同一排列。位置排列不改变 Pad 地址、快捷键、MIDI 或 Pattern 引用。

| 屏幕行（自上而下） | 左 1 | 左 2 | 左 3 | 左 4 |
| --- | --- | --- | --- | --- |
| 第一行 | 13 · G | 14 · H | 15 · J | 16 · K |
| 第二行 | 09 · A | 10 · S | 11 · D | 12 · F |
| 第三行 | 05 · T | 06 · Y | 07 · U | 08 · I |
| 第四行 | 01 · Q | 02 · W | 03 · E | 04 · R |

| 本 Bank 内序号 | Bank A／B／C／D 的地址 | 键盘 | MIDI note |
| --- | --- | --- | --- |
| 01 | A01／B01／C01／D01 | Q | 36 |
| 02 | A02／B02／C02／D02 | W | 37 |
| 03 | A03／B03／C03／D03 | E | 38 |
| 04 | A04／B04／C04／D04 | R | 39 |
| 05 | A05／B05／C05／D05 | T | 40 |
| 06 | A06／B06／C06／D06 | Y | 41 |
| 07 | A07／B07／C07／D07 | U | 42 |
| 08 | A08／B08／C08／D08 | I | 43 |
| 09 | A09／B09／C09／D09 | A | 44 |
| 10 | A10／B10／C10／D10 | S | 45 |
| 11 | A11／B11／C11／D11 | D | 46 |
| 12 | A12／B12／C12／D12 | F | 47 |
| 13 | A13／B13／C13／D13 | G | 48 |
| 14 | A14／B14／C14／D14 | H | 49 |
| 15 | A15／B15／C15／D15 | J | 50 |
| 16 | A16／B16／C16／D16 | K | 51 |

- 字母键按键盘的物理键位映射。
- MIDI note 36–51 对应当前 Bank 的 16 个 Pad。
- 按住键盘时的自动重复不会反复触发。
- 在文本框、下拉框或可编辑内容中打字，不算 Pad 输入。
- Pad 获得焦点后，Enter 或 Space 等同于按下和松开这个 Pad。
- 鼠标和触摸的力度固定为 100；MIDI 使用输入力度。
- 弹窗打开时，字母键并不会被统一屏蔽：焦点在弹窗按钮等非输入控件上时，字母键仍可能触发 Pad；能否发声仍取决于音频和 Project 状态。

**按下和松开**取决于所选 Pad 的 Playback 设置：

| 设置 | 按下 | 松开／再按 |
| --- | --- | --- |
| One Shot（Loop 关、One Shot 开） | 播放一次所选范围 | 松开不截断；再按重新触发。Release 不可用。声音播完，按压反馈才结束。 |
| Gate（Loop 关、One Shot 关） | 开始播放 | 松开时释放声音，Release 影响尾音。 |
| Loop Gate（Loop 开、Hold 关） | 开始循环 | 松开结束循环并进入释放。循环边界、Reverse、Crossfade 影响声音。 |
| Loop Toggle（Loop 开、Hold 开） | 开始循环并锁住 | 松开继续循环；再按同一个 Pad 停止。 |
| Mute 开 | 照常进入演奏和录音 | 没有声音。没有声音不代表没收到 Pad 事件。 |

这里的 Hold 指循环锁存，和 Perform 的 FX HOLD 不是一回事。

**任意页通用的 Pad 规则：**

- Pattern 录音中，在任何一页按下和松开 Pad 都会录进当前 Pattern。
- 默认声音正在加载、处理或失败时，该 Pad 显示 Loading／Processing／Failed，不能演奏；等声音准备好才能演奏。恢复入口见[第 9 章](#cross-page)。
- 页面失焦或隐藏、触摸被取消、切 Bank 或换页时，未松开的按压会被清除。

### 1.9 按住空 Pad 采样 \{#pad-capture\}

| 情况 | 操作 | 结果 |
| --- | --- | --- |
| 可以采样，其他录音空闲 | 按住空 Pad，再松开 | 按住期间录 System 所选的输入；正常松开后自动尝试保存到这个 Pad。成功后 Pad 显示为已分配并带颜色。 |
| 第一次使用，麦克风未授权 | 按一下或按住 | 只请求麦克风权限，这次不录音。授权后需要再按住一次。 |
| MIDI 输入 | 发 note | 不会开始采样，也不能代替用户申请麦克风权限。 |
| 另一种录音或状态挡住 | 按 Pad | 不开始采样，什么也不保存；按现有提示处理。 |
| 当前环境不支持按住采样 | 在 Sample 点空 Pad | 只选中空槽，可以从这里打开文件选择。选文件后还要裁剪和确认才写入 Pad。 |

- 同一时间只能有一个空 Pad 采样。
- 录音时触摸区显示目标 Pad 和时长。
- 录音开头严格为零的数字静音可以去掉。
- 打开 System、页面失焦、隐藏或按压被取消时，这次采样不会自动保存，而是等待确认：Save Pad recording 或 Discard Pad recording，见[第 9 章](#cross-page)。
- 这种待确认的录音没有裁剪手柄；和 Record Sample 的面板不同。

### 1.10 弹窗与 Escape \{#modal\}

- 弹窗打开时，Tab 和 Shift+Tab 只在弹窗内移动。
- Escape 执行该弹窗的取消或关闭，关闭后焦点回到打开它的控件。
- 点弹窗外的遮罩不会关闭弹窗。
- 弹窗打开时，背景不能用鼠标或触摸操作。字母键例外，见 [1.8](#pads)。
- Escape 和 Delete 在不同控件上含义不同：EQ 点、滑块、Capture 裁剪和网格各有规则，不能把一个规则套到所有控件。网格没有“Escape 删音符”。

### 1.11 保存与“声音准备好” \{#saving\}

- 作者内容自动保存，没有手动 Save 或 Save As 按钮。
- 本手册说的“生效”，指操作成功并且屏幕已经显示新结果。等待、失败或“已保存、声音还没准备好”都不算完成。
- 只改选中项、视图、草稿或设置表单，不产生新的作者编辑。
- 有时内容已保存，但新声音还不能播放：Project 上屏显示 Sample saved · audio pending，触摸区显示 Retry Prepare 或 Retry audio preparation。重试只重新准备声音，不重新导入。

### 1.12 全局状态速查 \{#states\}

| 状态 | 能做什么 |
| --- | --- |
| 启动中，Project 列表读取中 | 等待。上屏显示状态，触摸区显示加载或错误，Pad 和播放键暂不可用。 |
| 没有 Project | 只能新建、导入等。上屏显示 NO PROJECT。 |
| 正在打开、导入或保存 | 相关编辑、选择和部分导航要等完成；完成前看到的仍是旧内容。 |
| 音频未启动或已暂停 | 第一次有效的音乐操作会唤醒音频；部分按钮先唤醒再执行。触摸唤醒可能在松手时才完成。上屏显示音频状态，触摸区的试听提示随之变化。 |
| 任一种录音进行中或待处理 | 不能开始另一种录音，见 [1.4](#recordings)。Record Sample 面板打开时只能在面板里操作。 |
| System 打开 | 见[第 8 章](#system)。 |
| 已保存但声音未准备好、有待恢复的录音、Project 被占用、Runtime 故障 | 见 [1.11](#saving) 和[第 9 章](#cross-page)。 |

## 2. 已决定、待实现 \{#planned\}

## 4. Sample \{#sample\}

**控件速查卡**

| 控件 | 在 Sample 页的作用 |
| --- | --- |
| 左栏 | ENC1–ENC4、↑↓ 和不按 SHIFT 的 ← → 不可用；SHIFT + ← →、Play/Stop、Record 见[第 1 章](#global)。 |
| Bank | 所选 Pad 保留本 Bank 内序号（A03 → B03），只选择不演奏。Record Sample 已开始时可以换 Bank 演奏，但采样目标仍是原来的 Pad，录音不会写到新 Bank。 |
| 按已分配的 Pad | 选中它（白边加绿点）并按触发模式演奏。触摸区保持当前子页，显示新 Pad 的参数。选择本身不保存。 |
| 按空 Pad | 按住采样，见 [1.9](#pad-capture)；不支持时只选中空槽。 |
| 把音频文件拖到 Pad | 这个 Pad 成为导入目标；已有声音先确认替换。拖放本身不覆盖内容。 |
| 上屏 | Pad 地址、类别或空态、声道、采样率、总时长、Start–End、完整波形和范围标记。 |
| 触摸区 | Trim、Playback、Tone / EQ、Pad 四个子页，作用于同一个所选 Pad。 |

- 触摸区可以缩放波形；上屏始终显示完整波形。
- 裁剪草稿有效时，上屏的范围线和 Selection 立即跟着变，不等试听；取消后两边都回到已保存的范围。

### 4.1 子页与编辑规则 \{#sample-rules\}

- 第一次进入 Sample 显示 Trim。
- 换 Pad、换 Bank 或从 System 按 Back to music 回来，保持当前子页。
- 普通离开 Sample 再回来，回到 Trim。Record Sample 面板、Sequence 中的裁剪覆盖层等需要保持 Sample 状态的场合除外。
- 切子页会取消还没完成的试听草稿；已经按失焦规则保存的数值保留。
- 子页切换只改视图，不保存内容，也不演奏。
- 拖动参数时预览，松手、键盘步进结束或失焦时保存一次。
- 拖动中按 Escape 或手势被取消，放弃这次修改。
- 音频未启动时，裁剪画面仍可预览，但听不到试听。
- 预览被拒绝时草稿清除；之后晚到的松手不会保存。

### 4.2 Trim \{#trim\}

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 已分配 | Start／End 手柄、范围滑块、秒数输入 | 改播放起止。范围始终有效且不为空。手势结束才保存。只改播放范围，不裁掉原音频。 |
| Loop 开 | Loop start 秒数输入 | 改循环起点，限制在播放范围内。 |
| Forward 循环 | Loop crossfade 毫秒输入 | 改循环接缝的交叉淡化。Ping-pong 没有这个输入。上屏不显示该值。 |
| 已分配 | Zoom In／Zoom Out／Fit／Pan Left／Pan Right | 放大、缩小、看全部、左右移动触摸区的波形窗口。只改视图。 |

### 4.3 Playback \{#playback\}

| 操作 | 结果 |
| --- | --- |
| Loop／One Shot（Loop 开时此键叫 Hold） | 切换触发模式，组合见 [1.8](#pads)。之后的演奏按新模式。 |
| Forward／Ping-pong（Loop 开时） | 单向循环或往返循环。选 Ping-pong 时 Crossfade 隐藏并清零。 |
| Mute／Reverse | 静音或反向，立即保存。Mute 不删除已录入的事件。 |
| Volume／Pitch／Pan | 音量 −60 至 +6 dB，音高 ±24 半音，左右声像。 |
| Attack／Release | Attack 0–2000 ms，Release 0–4000 ms。最短 2 ms 防爆音：显示 0–2 ms 时都按 2 ms。One Shot 时 Release 不可用。 |

### 4.4 Tone / EQ \{#tone\}

| 操作 | 结果 |
| --- | --- |
| Tone | 负值低通，正值高通，−2 至 +2 为 Off。 |
| 拖动 EQ 的三个点，或聚焦后按方向键 | 横向改频率，纵向改增益。低点和高点拖进 Cut 区时为切除。回到 0 dB 时该段不起作用。 |
| 中段：双击或双指触后上下拖动；聚焦后 Shift+↑↓ | 调 Q。普通拖动仍改频率和增益。手势结束保存一次，Escape 取消。 |
| 焦点在 EQ 点上时按 Delete／Backspace | 关闭这一段 EQ。不会删除 Pad。 |

空 Pad 在 Tone / EQ 页显示 Add Sample。

### 4.5 Pad 子页 \{#pad-page\}

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 空 Pad（任一子页） | Add Sample | 打开本地音频选择，选好后进入[长源裁剪](#long-source)。Commit 前不写入 Pad。 |
| 已分配 | Replace Sample | 选好文件后先确认替换（Confirm replace／Cancel replace／Escape）。确认后仍要经过导入裁剪。 |
| 已分配或有待导入数据 | Delete | 停止这个 Pad，清除待导入数据和试听，删除声音。Pad 变空、颜色回中性，仍保持选中。Pattern 中对这个 Pad 的引用不变。 |
| 已分配 | Reset Pad to Defaults → Confirm reset | 保留声音和颜色，恢复完整范围和播放默认值。Cancel reset 或 Escape 不改内容。 |
| 已分配且可以改色 | 五个 PAD COLOUR 色块 | 设置这个 Pad 的颜色。Pad 边框变色，Sequence 的上屏轨道、网格标签和音符随后也用这个颜色。不改声音。选同一颜色不产生编辑。 |
| 有自定义颜色 | Restore category default | 回到类别默认颜色或中性色。可以 Undo。 |
| 录音空闲 | Record Sample | 已分配时先确认替换；空 Pad 直接打开 [Record Sample 面板](#capture)。总是用麦克风，与 System 中空 Pad 采样的输入来源无关。 |
| 任意 | Sample details 折叠项 | 只读：Asset ID、源格式、帧数、修订号；空 Pad 显示未分配。 |
| 已保存、声音未准备好 | Retry Prepare | 重新准备已保存的声音，成功后 Pad 恢复可演奏。不重新导入。 |
| 支持 Slice，且 Pattern 停止 | Slice | 进入 Slice，见 [7.2](#slice)。不自动分析或分配。 |

- 真正替换声音时，播放参数恢复默认，自定义颜色保留。
- Delete 清除颜色；Reset 保留颜色。
- 录音中、命令处理中、参数草稿未完成或另一项保存进行中时，不能改颜色。

### 4.6 文件导入：长源裁剪 \{#long-source\}

文件入口接受 WAV、MP3、M4A、AAC、FLAC 等，实际能读的格式取决于浏览器。保存的是统一格式的音频。

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 已解码 | Selection start／length 滑块 | 在源音频里选一段。长度受目标 Pad 和 Bank 的容量限制。只改草稿。 |
| 选段有效 | Preview selection／Stop preview | 本地试听或停止。不保存。 |
| 可以提交 | Commit selection | 把选段写入目标 Pad。成功后面板关闭，上屏显示新波形；失败时面板保留并显示错误。颜色规则与普通替换相同。 |
| 面板内 | Delete Pad | 删除所选 Pad 的声音，不只是取消这次文件选择。 |
| 未提交 | Cancel／Escape | 放弃这次导入，回到 Sample，原内容不变。 |

面板打开时背景不能操作。

### 4.7 Record Sample 面板 \{#capture\}

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 空闲或权限被拒 | Record into Pad | 请求麦克风权限并开始录音，显示输入电平、波形和时长。其他录音进行中时不可用。 |
| 录音中 | Stop | 停止录音，进入裁剪。不会自动保存。 |
| 录音中 | Continue in Sequence | 进入 Sequence，面板在后台继续录音。按原目标 Pad 可停止，之后裁剪面板覆盖在 Sequence 上。 |
| 裁剪中或保存失败 | Start／End 手柄、范围输入或方向键 | 选择要保存的片段，阴影、起止和时长同步。Escape 取消正在进行的拖动或按键修改。 |
| 裁剪中或保存失败 | Crop to selection | 丢掉选区外的音频，只留选中部分。尚未写入 Pad。 |
| 裁剪中或保存失败 | Commit | 把选段写入原目标 Pad。失败时录音保留，可以重试；“已保存但声音未准备好”与“保存失败”分开提示。 |
| 裁剪中或保存失败 | Discard | 丢掉这次录音，原内容不变。 |
| 任意 | Close／Escape | 停止麦克风并关闭面板，不保存。 |
| 录音中失焦、隐藏、设备变化或达到容量上限 | 自动停止 | 保留已录片段并说明原因，可以 Commit 或 Discard。自动停止不等于保存。 |

- 录音期间，所选 Pad 显示 Capturing。
- 再按原目标 Pad 会停止录音，不会演奏它。
- 按其他已分配的 Pad 照常演奏，不改变采样目标。
- 面板是弹窗，背景不能操作；Continue in Sequence 是唯一离开面板而不停止录音的出口。
- 这个面板没有试听已录片段的按钮。
- 与[按住空 Pad](#pad-capture)不同：这里 Stop 后必须 Commit；按住空 Pad 正常松手会自动尝试保存。

## 5. Sequence \{#sequence\}

**控件速查卡**

| 控件 | 在 Sequence 页的作用 |
| --- | --- |
| ENC1 | EDIT 中每格移动一个小节，到边界停住；轨道名称列不动。SETUP 中网格不显示，ENC1 不可用。只改视图。 |
| ENC2 | 上屏的 8 行窗口每格移动一条轨道（A01–D16）。不换 Bank，不滚动触摸区网格。 |
| ENC3 | Tempo，每格 1 BPM，40–240。规则见 [1.7](#encoders)。 |
| ENC4 | Swing，每格 1%，50–75%。规则见 [1.7](#encoders)。 |
| ↑ ↓ | 当前 Pad 前移或后移，A01–D16，可跨 Bank，到两端不可用。只导航，不演奏、不加删音符。 |
| ← →（SHIFT 关） | 停止时切到上一个或下一个 Pattern，到两端不可用。播放、录音或命令处理中不可用。 |
| SHIFT + ← →、Play/Stop、Record | 见[第 1 章](#global)。 |
| Bank | 当前 Pad 保留本 Bank 内序号，上屏窗口跳到该 Bank 第一行，网格换成该 Bank 的 16 条轨道，清除音符选区。不发声。 |
| 16 个 Pad | 只演奏，不新增音符，也不移动当前 Pad。录音中会录入，见 [1.3](#transport)。 |
| 上屏 | BPM、Swing、bar／beat、播放状态、8 条轨道（地址和类别）、视窗框、当前 Pad、所选音符与力度。 |
| 触摸区 | EDIT（默认）和 SETUP 两层。 |

联动规则：

- ↑↓ 跨过 Bank 边界时自动换 Bank，上屏窗口移到能看见当前 Pad 的位置，已有的音符选区保留。
- ENC1 和触摸网格的横向滚动是联动的；ENC2 只滚上屏。
- 音符改动保存后，上屏和网格同时更新。
- 拖动 SETUP 的 Tempo／Swing 时，上屏立即显示草稿值；取消后回到已保存值。
- 打 Pad 的同时，播放头照常前进。

### 5.1 EDIT \{#sequence-edit\}

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 停止 | GROOVE 标题 → Pattern 列表 | 直接选择任一 Pattern，网格换内容，原音符选区清空。播放、录音或命令处理中不可用。 |
| Pattern 列表 | Cancel／Escape／点当前 Pattern | 关闭列表，焦点回到标题，不切换。 |
| 任意 | EDIT／SETUP | 切换网格和设置卡片。只改视图；离开再回来默认 EDIT。 |
| 没有进行中的音符手势 | Grid tools | 打开 Snap／NOTE／VEL 弹窗，显示当前设置。 |
| Grid tools | Snap 1/4／1/8／1/16／1/32／off | 改网格吸附。不改已有音符；不是录音的 Quantize。 |
| Grid tools | NOTE／VEL | 切换编辑位置或编辑力度。 |
| Grid tools 或 Choose bar 弹窗 | Done／Escape | 关闭弹窗，焦点回到入口，所选设置保留。 |
| NOTE | 轻点空白位置 | 新增一个该轨道的音符，起点和初始长度按 Snap。 |
| NOTE | 轻点已有音符 | 删除这个音符，不是选中；若它在选区中，也从选区移除。 |
| VEL | 轻点音符或空白处，不拖动 | 什么都不改。 |
| NOTE | 拖音符主体 | 移动时间或轨道；属于多选时整组移动。松手保存一次，超出范围时停在边界。拖动中上屏不显示草稿，不会触发目标 Pad。 |
| NOTE | 拖音符尾部 | 改长度。不影响 Sample 的裁剪。 |
| NOTE | 从空白处拖框 | 框选同一 Bank 的音符，上屏显示选区和力度摘要，出现 Delete／Clear。 |
| 有多选 | Delete／Clear | Delete 删除所有选中音符；Clear 只取消选择。 |
| VEL | 在音符上下拖 | 改力度 1–127；之后新增的音符使用这个力度（初始 100）。 |
| 没有进行中的音符手势 | 前／后小节、BAR 直接选择、ENC1 或横向滑动 | 查看其他小节。一屏显示一个小节，16 条轨道都可见，不用拖横向滚动条；BAR 显示实际范围，上屏视窗框只框出可见的时间范围。不清除音符选择。 |
| 拖动中 | 手势被取消或编辑对象失效 | 放弃这次拖动。 |
| 录音中或刷新中 | 网格编辑手势 | 不能开始编辑，提示 Recording 或等待刷新。Snap、NOTE、VEL 等视图设置仍可用。 |

网格中的轨道名称不是演奏按钮。

### 5.2 SETUP \{#sequence-setup\}

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 非录音、非命令处理中 | TEMPO 滑块、−／+ | 40–240 BPM。滑块松手保存；按钮每次 ±1。播放中也能改，按引擎的生效边界更新。 |
| 同上 | SWING 滑块、−／+ | 50–75%。滑块松手保存；按钮每次 ±1。作用于整个 Pattern。 |
| Tempo／Swing 拖动中 | Escape、手势取消、换编辑对象、打开 System、开始录音 | 放弃草稿，回到已保存值；之后晚到的松手不会保存。 |
| 非录音、非命令处理中 | TAP | 按连续点按的间隔算 Tempo。第一次点按只是起点，有了有效间隔才保存。 |
| 停止 | BARS 1／2／4／8 | 改**当前** Pattern 的长度。变长补空小节；变短删除或截短越界音符。点当前长度不改。 |
| 停止，长度小于 8 | DOUBLE UP | 长度加倍并重复已有音符。到 8 小节时不可用。 |
| 停止 | COPY | 复制当前 Pattern 并切到副本。不同于 Project 的 DUPLICATE。 |
| 停止 | + NEW → 长度 1／2／4／8 → CREATE | 新建空 Pattern 并切过去。选长度不改旧 Pattern；CANCEL 只收起表单。 |
| 非录音、非命令处理中 | QUANTIZE | 开关录音量化，Perform 上屏显示新设置。不重写已有音符。 |
| 任意，包括录音中 | METRONOME | 开关节拍器。这是本设备的设置，不保存到 Project；只在 Pattern 播放时发声。 |

## 附录：实现与验证 \{#appendix\}

### A.1 术语对照 \{#terms\}

正文用用户语言；对应的实现术语如下。

| 正文说法 | 实现术语 |
| --- | --- |
| 生效、保存后显示 | 操作成功并完成**回读**（re-read）后的**投影**（projection）。等待、失败或 publication pending 都不算完成。 |
| 作者编辑、保存 | 一次 authoring 提交，Project **修订号**（revision）加一。只改选中项、视窗、草稿或设置表单不加修订号。 |
| 保存本轮录入的事件 | Pattern 事件录音的**结算**（settle）与回读。 |
| 命令处理中 | 传输命令正在结算；灯与上屏等权威状态回读，可能显示 publication pending。 |
| 已保存、声音未准备好 | 作者修订已保存，Runtime 尚未发布（prepare／cook 失败，stale runtime revision）。 |
| 控制台暂时不接受操作 | Undo/Redo 执行时整个控制台 inert。 |
| 背景不能操作 | 模态弹窗把背景设为 inert；它不屏蔽全局音乐键。 |
| Bank 键不会切换 | 控件仍显示，但 reducer 拒绝 `bank-selected`。 |
| System 打开时左栏属于原页面 | `activeMode` 不变，只是 System 覆盖触摸区。 |

### A.2 精确条件与实现细节 \{#conditions\}

**左栏与传输**（`app.tsx`）

- Play/Stop 可用：`transportReady && !transportBusy`。`transportReady` 要求 Pattern transport 会话、Project ready、可开始手势，且音频 running，或 Runtime 处于 audio-suspended 且音频 inactive／suspended。
- Record 可用：在 Play 条件之外，还要求空 Pad 采样空闲、Record Sample 面板为 idle／permission-error、演出阶段为 idle／saved／discarded。
- Play/Stop 与 Record 在 audio 未运行时先 `activateAudio`，等唤醒成功且 Project、会话和手势 epoch 未变才提交意图。
- 页面键：`selectMode` 关闭 System、`clearPressed()`、清 SHIFT；离开 Perform 时先 `performController.leave()`。
- Sequence 键：`isSequenceSession && project ready && current !== null`。
- Perform 键：只要求 `project ready && current !== null`（`app.tsx:2699`）。Perform 触摸区的能力就绪条件另行要求 performController 与 capture storage（`app.tsx:2491`）。
- Bank：`selectBank` 先清按压与 SHIFT，再 dispatch；`isCreatorActionAllowed` 不允许时 reducer 拒绝。Runtime／Project 未就绪或 `transfer.phase !== "idle"` 时拒绝；播放／录音本身不拒绝。Sample 页未武装 Capture 时同步 `slot-selected`。
- ↑↓ 与 Bank 使用同一允许条件（`padNavigationAvailable`）。
- ← → 切 Pattern：`patternStepOpen` 要求 Sequence 页、`!playing`、未锁定设置、Pattern 索引有效。SHIFT 关且非 Sequence 时，Undo/Redo 键保持禁用。

**旋钮**（`state/encoder_input.ts`、`app.tsx`）

- `ENCODER_IDLE_COMMIT_MS = 400`；停转后一次提交即一次 authoring 提交和一条 Undo。回到起点不提交。
- 上一次提交还在路上时，新一轮从该请求值开始；提交失败后 `forget()`，下一轮从 Truth 开始。
- 录音或传输结算时 `cancel()`；换页、打开 System、换 Project、换所选 Pattern 时 `cancel()` 加 `forget()`（`app.tsx:2531-2538`）。
- 网页拖动每 8 px 一格，滚轮累计 50 px 一格（`physical_controls.tsx`）。
- 400 ms 最初是 Desktop Final 计划 T6 的提议；[2026-10-09 旋钮决定](https://github.com/endaye/lmdj/blob/main/docs/prd/decisions/2026-10-09-contextual-encoders-and-monitor-volume.md)已确认它。其他页面映射仍归[硬件映射问题 #1822](https://github.com/endaye/lmdj/issues/1822)和该决定，本页不替它们下结论。

**Pad 输入**（`pad_surface.tsx`、`input_controller.ts`、`input_adapters.mjs`）

- 键盘按物理 `code` 映射；全局键盘过滤只识别可编辑目标，没有独立的“弹窗打开即屏蔽”判断。
- 未完成的按压在 blur、hidden、pointercancel、切 Bank 或换页时清理。空 Pad 采样中断时封存为 review，而不是正常松手的自动提交；浏览器音频中断另有处理。
- 默认声音种子状态 Loading／Processing／Failed／saved-unavailable 时禁用该 Pad；内容可能仍显示旧投影。
- 空 Pad 采样的“待确认”在状态机中是 review → saving → idle，保存失败回到 review。

**Sample**

- 普通参数：移动时预览，pointerup、键盘步进结束或 blur 时提交一次；Escape 或 pointercancel 取消。预览被拒绝会清草稿，晚到的 pointerup 不提交。
- Ping-pong 连带清 `loopCrossfadeFrames`。
- 替换声音时恢复样本播放默认参数，Pad 颜色 override 保留；Delete 清除 Pad 播放与颜色信息；Pattern 引用 Pad Slot，不因 Delete 改为 Asset 引用。
- 改色禁用条件（`padColourDisabledReason`）：录音中；传输结算中；Project 或 Runtime 未 ready；改色进行中、投影刷新中、Sample 有 pending action 或文件传输中；Sample 草稿未完成。相同 override 不提交。
- 长源导入写入归一化音频；不能把旧的“仅 PCM16 WAV”错误提示当作入口的全部能力。

**Sequence**

- 写入类网格手势在录音或投影回读中禁止开始；音符改动松手一次提交，边界按有效范围钳制。
- Refresh playback 按同一命令身份协调未确定的命令，不是再次反向切 Play/Record。

**Perform**

- Pattern Launch 仅在演出录制 recording／flushing 时可用（`perform_surface.tsx`、`perform_state.ts`），记录为演出 launch 操作，等待权威确认；上屏由全局 Pattern 投影驱动，不把 queued 当作立即换曲。
- Filter／Delay 等推子是 engage → move → release 手势；非录制时走实时 FX，录制中同时记录演出 FX 操作。HOLD 按引擎 hold 规则保留。
- Save Performance 后 `bindingStatus` 可能需要 Retry WAV bind；不假装 WAV 已绑定。
- Replay 状态 playing／idle／neutral 与 resolved revision 独立回读；Stop Replay 请求停止并中和 replay 状态。

**Sound Sets 与 Slice**

- 安装使用预览时的 Bank 与 Project revision；Project 已变化时保留拒绝，Refresh mapping 后重新确认。安装后修订和 Asset 计数在 System 详情。
- Provider 选择与权限是 Workspace 设置，不写 Project Truth；Slice 分析结果是候选，不写 Project Truth。
- Adopt 结果不确定时先 Refresh，不自动重试。

**System 与恢复**

- Pad recording source 存在设备 `localStorage`。
- Project 打开需取得项目锁；Retry project 不强制夺锁；Continue here 的对方可 refused 或 unanswered，未答复不是授权。
