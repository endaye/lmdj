## 1. 整机与全局规则 \{#global\}

### 1.1 控制台四区 \{#console\}

<ConsoleDiagram />

- **左栏**：Logo（即 System 入口）、2×2 的 ENC1–ENC4，以及八行按键：PRJ｜SMP、SEQ｜PRF、A｜B、C｜D、SHIFT（占一整行）、↑｜↓、←｜→、REC｜PLAY。模式与录放键保留 Project／Sample／Sequence／Perform／Record／Play/Stop 的完整可访问名称；[布局参考](https://github.com/endaye/lmdj/blob/main/docs/design/2026-09-11-lmdj-hardware-ui-layout-reference.md)第 4 节的 −／+ 行目前不存在；Interaction UI 将 SHIFT 移到 Bank 后的第 5 行，方向键为第 6、7 行。原生 Tab 遵循这个顺序，禁用键被跳过。
- **上屏**：只读反馈区，顶部显示当前对象和全局 Pattern 播放状态／位置，中部显示模式事实，底部显示四个实际旋钮功能和读数。没有 Project 时不虚构位置。它没有可点击的音乐按钮、旋钮、波形拖拽点或网格编辑点。编辑都来自左栏、Pad 和触摸区。
- **16 个 Pad**：当前 Bank 的 16 个声音槽，地址见 [1.8](#pads)。
- **触摸区**：内容随当前页面变化，各页分别说明。

### 1.2 页面键与 System 入口 \{#pages\}

按任一页面键都会关闭 System、清除 SHIFT、未松开的按压和未提交旋钮草稿。普通换页不停止全局 Pattern 播放或录音。离开 Perform 或打开 System 时，旋钮拥有的效果手势按已有 HOLD 规则释放。

| 按键 | 可用条件 | 结果 |
| --- | --- | --- |
| Project | 任意时候 | 进入 Project。 |
| Sample | 任意时候 | 进入 Sample。普通重新进入时显示 Trim 子页。 |
| Sequence | Project 已打开且支持 Sequence | 进入 Sequence，默认显示 EDIT。 |
| Perform | Project 已打开 | 进入 Perform。缺少音频或录音存储时，触摸区说明还在等待什么。 |
| 从 Perform 换到其他页 | 任意时候 | 先结束 Perform 的演出录制和 Replay，再换页。已停止、待保存的演出保留。 |
| Logo（System） | 任意时候 | 打开 System，见[第 8 章](#system)。 |

没有打开的 Project 时，上屏显示 NO PROJECT，Sequence 与 Perform 键不可用。

### 1.3 播放与录音：Play/Stop 与 Record \{#transport\}

左栏 Play/Stop 和 Record 在**每一页**都只控制全局 Pattern，不会变成采样或演出录音。

| 状态 | Play 灯 | Record 灯 | 此时的限制 |
| --- | --- | --- | --- |
| 停止 | 灭 | 灭 | 只有此时能改 Pattern 长度和结构、切 Pattern 立即生效。 |
| 播放 | 亮 | 灭 | 可以打 Pad，可以改 Tempo／Swing，也可以按 SEQ SNAP 的 1 BEAT／1 BAR／SEQ END 边界切 Pattern；默认 1 BAR。不能改长度或结构。 |
| 录音 | 亮 | 亮 | Pad 事件录入当前 Pattern；Sequence 网格编辑、Tempo／Swing／Quantize、Pad 改色和切 Pattern 不可用；录音中无缝切换已批准、尚未交付，见[第 2 章](#planned)。 |
| 命令处理中 | 等结果 | 等结果 | Play/Stop、Record、切 Pattern 和相关设置暂不可用；以灯的最终状态为准。 |

| 当前状态 | 按键 | 结果 |
| --- | --- | --- |
| 停止 | Play/Stop | 当前 Pattern 开始循环播放；需要时先唤醒音频。不改作者内容。 |
| 播放 | Play/Stop | 停止 Pattern。不会关闭整个音频引擎；手打 Pad 仍按各自的触发模式发声。 |
| 录音 | Play/Stop | 停止播放并保存本轮录入的事件；保存后网格显示这些事件。失败时保留提示和恢复入口。 |
| 停止 | Record | 同时开始播放和录音。 |
| 播放 | Record | 从当前位置开始叠录，不从头重新播放。 |
| 录音 | Record | 结束录音并保存事件，Pattern 继续播放。 |
| 没有 Project、音频未就绪、命令处理中或另一种录音进行中 | 任一键 | 按键不可用。Play 与 Record 的条件不完全相同，见[附录 A.2](#conditions)。 |

- 录音中屏幕上即时出现的事件还没有保存；结束录音才保存。
- 按 Play/Stop 或 Record 会清除 SHIFT。

### 1.4 三种录音 \{#recordings\}

| 入口 | 录什么 | 怎样保存 |
| --- | --- | --- |
| 左栏 REC（Record） | Pad 事件，录进当前 Pattern | 再按 Record 或按 Play/Stop 时保存。 |
| 按住空 Pad（任意页） | 一段音频，录进这个 Pad；来源在 System 选麦克风或内部播放 | 正常松手后自动尝试保存，见 [1.9](#pad-capture)。 |
| Sample 的 Record Sample | 麦克风音频，录进所选 Pad | Stop 后必须按 Commit，见 [4.7](#capture)。 |
| Perform 的 Record Performance | 演出操作和主输出 WAV | Stop 后在 Takes 按 Save，见[第 6 章](#perform)。 |

一种录音进行中时，其他录音入口不可用或不会开始。

### 1.5 Bank 键与当前 Pad \{#bank\}

Bank A／B／C／D 把下边 16 个 Pad 换成该 Bank 的 A01–A16／B01–B16／C01–C16／D01–D16。

- Bank 键不改 Pad 内容、Pattern 或作者内容。
- Bank 键会清除 SHIFT、未松开的按压，以及 Sequence 中点 Bank 前的音符选区。
- Pattern 播放或录音时也能切 Bank。
- Project 未就绪、Runtime 未就绪或文件正在传输时，Bank 键仍显示，但不会切换。

全机共用一个**当前 Pad**：Sample 编辑对象与 Sequence 当前行指向同一槽位。

- 正常击打可用的 Pad（鼠标、触摸、键盘或 MIDI）会选中它并按播放模式演奏；Sequence 的当前行也跟着变。选择本身不保存，也不新增音符；Pattern 录音中的演奏仍会录入。
- **Bank 键只切换可演奏的 16 个槽，保留当前 Pad。** 例如选 A03 后按 Bank B，Sample 仍编辑 A03，可见的 B01–B16 没有代表 A03 的选中框；再打 B05 才改为编辑 B05。
- Sequence ↑↓ 按 A01–D16 选择当前 Pad，并同步 Sample 编辑对象，只导航不演奏。它从当前 Pad 出发，必要时切回该目标所在 Bank；到首尾停止。首次选择前，Sequence 以当前 Bank 的第一个槽作为起点。
- Sample 中可见的当前 Pad 显示白边加绿点；Sequence 只在当前 Pad 落入上屏八行窗口时高亮该行。打 Pad 不强制滚动该窗口，ENC2 仍可独立查看其他行。
- Record Sample 已武装时，采样目标保持原槽；其他 Pad 可以演奏，但不会把正在录入的目标改走，见 [4.7](#capture)。

### 1.6 SHIFT 与 Undo/Redo \{#history\}

- SHIFT 是点一下开、再点一下关的锁存键。它本身不改任何内容。
- SHIFT 打开时，← 是 Undo，→ 是 Redo，每次撤销或重做一次作者编辑。
- ← → 的灯在有可撤销或可重做的编辑时亮。灯亮不代表不开 SHIFT 也能按。
- SHIFT 关闭时，← → 在 Sequence 切 Pattern，在其他页不可用。
- SHIFT 在换页、换 Bank、按 Play/Stop 或 Record、完成一次 Undo/Redo 后自动关闭。
- Undo/Redo 恢复的是已保存的作者内容，例如 Pad 分配和颜色；它不撤销播放、下载或导出。
- Undo/Redo 会清除 Sample 中未完成的参数草稿，并刷新各页显示。
- 同一 Project 的历史已就绪时，普通换页保留 Undo/Redo 的可用状态。历史被阻断、结果未确定、发生操作失败或需要核对恢复状态时仍会重新读取；换页不会绕过这些等待。
- 没有历史、采样或演出待处理、触摸参数草稿未完成或正在保存时，Undo/Redo 不可用。可取消的旋钮草稿先取消，再执行历史；不能用 Undo 绕过已经发出的作者操作。
- Undo/Redo 执行期间，整个控制台暂时不接受操作。
- SHIFT＋ENC1–3 使用细调；导航和整数 BPM 保留最小步长。ENC4 没有第二功能，也没有粗调层。

桌面键盘的 `Cmd/Ctrl+Z` 与 `Cmd/Ctrl+Shift+Z` 也分别对应 Undo／Redo；Creator 忽略带 Ctrl／Cmd 的 Pad 按下，保留应用／浏览器快捷键，组合键不会额外激活音频、选择或击打 Pad，也不会发起采样／导入或停止 Capture。只带 Alt／Shift 的按键保留现有 Pad 行为；先前普通按下的 Pad 在松手时仍释放，即使此时已按住 Ctrl／Cmd。输入框中仍保留原生文字撤销。

### 1.7 旋钮与方向键 \{#encoders\}

- 旋钮用滚轮、上下拖动，或聚焦后按方向键转动。向上、向右是增加，向下、向左是减少。
- 单击旋钮没有额外动作。
- ENC1–3 随页面和参数组变化，见 Project、Sample、Sequence 和 Perform 的控件速查卡。System／Sound Sets／Slice 的 ENC1–3 未分配。上屏持续显示四个当前功能和数值。
- ENC4 在所有页面固定为 Output Volume：每格 1%，范围 0–100%，默认 100%，可恢复已记住的 0%。监听会话和偏好恢复就绪后才可转动。它立即改变本设备监听，包括节拍器；音量存 IndexedDB，不写 Project／Undo，也不改变录音、重采样或导出电平。
- ↑↓ 在 Sample／Sequence／Perform 选择同一个当前 Pad，在 Project 的单列列表选择相邻工程并滚入可见范围。Perform 按 A01–D16 首尾停止，跨界同步 Bank，并在矩阵中高亮；SHIFT 或 System 中不提供 Perform Pad 方向。Project／Sample 的 SHIFT＋↑↓ 未分配；完整 Perform 三组导航仍待滤波接线，见[第 2 章](#planned)。
- ← → 不按 SHIFT 时在 Project 未分配、Sample 切现有子页、Sequence 切 Pattern；按 SHIFT 时在所有页面做 Undo/Redo。左栏方向按钮不接管文本输入或聚焦旋钮的键盘方向键。
- Sample 工程参数转动时立即预览，同一 Pad 的多参数停转 400 ms 后合并为一次保存／Undo。转回起点不保存。Sequence ENC3 的 BPM 当前只有即时读数预览，播放和节拍器仍等提交后发布；可听即时预览尚未实现。
- Sample 作者锁定、Sequence 录音或传输结算时，相关工程参数旋钮不可用，未提交的预览作废；ENC4 保持监听职责。
- 未提交的 Sample／BPM 旋钮草稿在离页、切 Pad／Project／Pattern、打开 System、Escape 或 Undo／Redo 前取消。下一轮从已保存的值开始；已经发出的请求保留真实结算结果。
- Perform 旋钮停转或切组（主组／FILTER／FX·MORE）保持效果值与手势；离开 Perform／打开 System 按 HOLD 释放拥有的手势。七段单值效果之外，Filter 是独立参数组（LP／HP／BP、20 Hz–20 kHz 对数 Cutoff、0–100% Resonance），初值 OFF／LP／20 kHz／0%，读回只认 Core，进 FILTER 组不发声。

这些映射、细调、监听记忆和 400 ms 生命周期遵循[已批准的旋钮决定](https://github.com/endaye/lmdj/blob/main/docs/prd/decisions/2026-10-09-contextual-encoders-and-monitor-volume.md)。Swing 保留在 Sequence SETUP 触摸区。可听 BPM 已批准[保持当前音乐位置继续播放](https://github.com/endaye/lmdj/blob/main/docs/prd/decisions/2026-10-10-sequence-audible-tempo-preview.md)，完整实现与验收仍待完成。

### 1.8 16 个 Pad：地址、键盘与 MIDI \{#pads\}

四个 Bank 共 64 个声音槽，每次显示 16 个。每个格子的行为相同，只是目标槽不同。

屏幕按 MPC 方向排列：左下是 01，向右到 04，再向上逐行增加。Tab 焦点按屏幕从上到下、从左到右访问可用的 Pad。Sound Set 安装预览也用同一排列。键盘键位只改变键盘与 Pad 的对应关系，不改变这套位置排列、Pad 地址、MIDI 或 Pattern 引用。

**键盘与 MIDI：** 键盘从上到下的四排，分别对应屏幕从上到下的四行；MIDI note 36–51 按序号对应 01–16。切 Bank 只改变地址前缀 A／B／C／D，下表的相对映射对四个 Bank 相同。此表与整机示意图、新版 Figma 所有页面的 Pad 键帽一致，依据[四排空间映射决定](https://github.com/endaye/lmdj/blob/main/docs/prd/decisions/2026-10-11-creator-keyboard-spatial-mapping.md)。

| 屏幕行（自上而下） | 左 1 | 左 2 | 左 3 | 左 4 |
| --- | --- | --- | --- | --- |
| 第一行 | 13 · 键 1 · note 48 | 14 · 键 2 · note 49 | 15 · 键 3 · note 50 | 16 · 键 4 · note 51 |
| 第二行 | 09 · 键 Q · note 44 | 10 · 键 W · note 45 | 11 · 键 E · note 46 | 12 · 键 R · note 47 |
| 第三行 | 05 · 键 A · note 40 | 06 · 键 S · note 41 | 07 · 键 D · note 42 | 08 · 键 F · note 43 |
| 第四行 | 01 · 键 Z · note 36 | 02 · 键 X · note 37 | 03 · 键 C · note 38 | 04 · 键 V · note 39 |

- 例如 Bank B 时，键 Z 演奏 B01，键 1 演奏 B13，note 36 演奏 B01。
- 按住键盘时的自动重复不会反复触发。
- 在文本框、下拉框或可编辑内容中打字，不算 Pad 输入。
- Pad 获得焦点后，Enter 或 Space 等同于按下和松开这个 Pad。
- 鼠标和触摸的力度固定为 100；MIDI 使用输入力度。
- 弹窗打开时，字母键和数字键并不会被统一屏蔽：焦点在一般弹窗按钮等非输入控件上时，这些键仍可能触发 Pad；能否发声仍取决于音频和 Project 状态。Sample 精确输入表单拥有自己的按键，不触发键盘 Pad。

**按下和松开**取决于所选 Pad 的 Playback 设置：

| 设置 | 按下 | 松开／再按 |
| --- | --- | --- |
| One Shot（Loop 关、One Shot 开） | 播放一次所选范围 | 松开不截断；再按重新触发。Release 不可用。声音播完，按压反馈才结束。 |
| Gate（Loop 关、One Shot 关） | 开始播放 | 松开时释放声音，Release 影响尾音。 |
| Loop Gate（Loop 开、Hold 关） | 开始循环 | 松开结束循环并进入释放。循环边界、Reverse、Crossfade 影响声音。 |
| Loop Toggle（Loop 开、Hold 开） | 开始循环并锁住 | 松开继续循环；再按同一个 Pad 停止。 |
| Mute 开 | 照常进入演奏和录音 | 没有声音。没有声音不代表没收到 Pad 事件。 |

这里的 Hold 指循环锁存，和 Perform 的 FX HOLD 不是一回事。

**任意页通用的 Pad 规则：**

- Pattern 录音中，在任何一页按下和松开 Pad 都会录进当前 Pattern。
- S6 的积压接纳规则：Pattern 和 Performance 合计最多保留 64 次真实按压，同一次按下进入两种录音只算一次。满额时拒绝新的按压，已经接收的按压仍能松开；不能因录音写入延迟丢掉松键。
- Performance 录音中的 Pad、FX 和 HOLD 按操作顺序提交。写入等待期间，Pad 仍按真实按下占位，FX 松开保留在原手势之后；后来的 Pad 不越过较早的 FX。
- 普通 Pad 请求超时后，如果 Runtime 仍正常运行且原操作尚在完成，Record-off／Stop 仍可使用，松键仍交给原按压处理。确认尚未提交的按下请求过期时，同样只报告本次输入失败；松键请求的明确失败仍按原故障规则处理。原始错误保留在 Developer diagnostics 的 `Pad input` 记录中。这种等待超时本身不触发重启，也不意味着录音已经保存。Runtime 确实失败、恢复探测失败或结果不明时，仍按原规则处理故障与恢复。
- 默认声音正在加载、处理或失败时，该 Pad 显示 Loading／Processing／Failed，不能演奏；等声音准备好才能演奏。恢复入口见[第 9 章](#cross-page)。
- 页面失焦或隐藏、触摸被取消、切 Bank 或换页时，未松开的按压会被清除。

### 1.9 按住空 Pad 采样 \{#pad-capture\}

| 情况 | 操作 | 结果 |
| --- | --- | --- |
| 可以采样，其他录音空闲 | 按住空 Pad，再松开 | 按住期间录 System 所选的输入；正常松开后自动尝试保存到这个 Pad。成功后 Pad 显示为已分配并带颜色。 |
| 第一次使用，麦克风未授权 | 按一下或按住 | 只请求麦克风权限，这次不录音。授权后需要再按住一次。 |
| MIDI 输入 | 发 note | 不会开始采样，也不能代替用户申请麦克风权限。 |
| 另一种录音或状态挡住 | 按 Pad | 不开始采样，什么也不保存；按现有提示处理。 |
| 当前环境不支持按住采样 | 在 Sample 点空 Pad | 只选中空槽，可以从这里打开文件选择。选文件后还要裁剪和确认才写入 Pad。 |

- 同一时间只能有一个空 Pad 采样。
- 录音时触摸区显示目标 Pad 和时长。
- 录音开头严格为零的数字静音可以去掉。
- 打开 System、页面失焦、隐藏或按压被取消时，这次采样不会自动保存，而是等待确认：Save Pad recording 或 Discard Pad recording，见[第 9 章](#cross-page)。
- 这种待确认的录音没有裁剪手柄；和 Record Sample 的面板不同。

### 1.10 弹窗与 Escape \{#modal\}

- 弹窗打开时，Tab 和 Shift+Tab 只在弹窗内移动。
- Escape 执行该弹窗的取消或关闭，关闭后焦点回到打开它的控件。
- 点弹窗外的遮罩不会关闭弹窗。
- 弹窗打开时，背景不能用鼠标或触摸操作。键盘 Pad 键例外，见 [1.8](#pads)。
- Escape 和 Delete 在不同控件上含义不同：EQ 点、滑块、Capture 裁剪和网格各有规则，不能把一个规则套到所有控件。网格没有“Escape 删音符”。

### 1.11 保存与“声音准备好” \{#saving\}

- 作者内容自动保存，没有手动 Save 或 Save As 按钮。
- 本手册说的“生效”，指操作成功并且屏幕已经显示新结果。等待、失败或“已保存、声音还没准备好”都不算完成。
- 只改选中项、视图、草稿或设置表单，不产生新的作者编辑。
- 有时内容已保存，但新声音还不能播放：Project 上屏显示 Sample saved · audio pending，触摸区显示 Retry Prepare 或 Retry audio preparation。重试只重新准备声音，不重新导入。

### 4.1 子页与编辑规则 \{#sample-rules\}

- 第一次进入 Sample 显示 Trim。
- 换 Pad、换 Bank 或从 System 按 Back to music 回来，保持当前子页。
- 普通离开 Sample 再回来，回到 Trim。Record Sample 面板、Sequence 中的裁剪覆盖层，以及更新 consumer／结果读回／投影仍在结算的场合保留同一个 SampleSurface；结算完成后沿用普通挂载规则。
- 触摸页签或左栏普通 ←/→ 切子页都先取消未提交旋钮／精确输入试听；↑/↓ 换 Pad 使用同一取消入口。range 已按失焦规则保存的数值保留，精确输入的失焦不保存；已发出的保存仍保留原结算结果。
- 子页切换只改视图，不保存内容，也不演奏。
- 拖动页面上的参数滑块时预览，松手、键盘步进结束或失焦时保存一次。
- 拖动中按 Escape 或手势被取消，放弃这次修改。
- 点击 Volume／Pitch／Pan／Attack／Release／Tone 的数值打开精确输入，从已保存值开始；合法且符合步长的数值立即预览。面板锚定右侧触控区，竖屏时保持正向，固定原 Pad 并分开显示草稿与已保存值。面板内滑块和数值输入共用草稿，松手、键盘步进结束或失焦不保存。Apply 或 Enter 确认一次保存／Undo；回到已保存值不提交，停顿超过 400 ms 也不保存。
- 空值、非有限数、越界或不符合步长的输入不能试听或保存；非法替换清除前一个合法试听，仍可以修正。
- Escape／Cancel、切 Pad／Project／Asset／revision／Runtime session、离开页面／子页／System 或卸载取消尚未提交的精确草稿，恢复已保存参数并清除它拥有的试听。已发出的保存保留真实结果，不自动重发。
- 同 Project 的 Runtime Session 重开保留 update 原 pending 和已知提交／publication failure／冲突／未知结果，只恢复读回与投影；普通新建／导入／切换 Project 仍等更新结算完成。旧 Pad 的结果刷新 Project Truth，不覆盖当前所选 Pad 的 playback。App 的 consumer ownership 信号不是实际 wire-send 证据。
- 精确输入弹窗的背景不可点击，数值按钮、输入和操作有至少 44 px 命中区；输入的 Undo 保留原生文本编辑。既有 Project history 控制器路由被调用时，先取消未提交草稿再恢复历史；弹窗内没有新增 Project Undo 快捷键。
- 音频未启动时，裁剪画面仍可预览，但听不到试听。
- 预览被拒绝时草稿清除；之后晚到的松手不会保存。
- Trim / Pitch 和 Pad Sound 按钮切换旋钮组，不改变 Pad 或新增保存。Start／End 每格 10 ms，SHIFT 一个源帧；Pitch 每格 1 半音，SHIFT 0.1 半音。Pad Volume 每格 1 dB，SHIFT 0.1 dB；Pan／Tone 每格 10 单位，SHIFT 1 单位。有效裁剪／循环范围沿用现有边界。
- 同一 Pad 的旋钮参数共用 400 ms 合并保存，见 [1.7](#encoders)。触摸接管或切 Sample 子页先取消未提交旋钮草稿；触摸松手、键盘完成或失焦的提交规则保持。

### 4.2 Trim \{#trim\}

波形下方是两列 Start／End 读数卡；循环时追加相应的循环读数。
视窗按钮按 Zoom Out、Zoom In、Fit 一行，再 Pan Left、Pan Right 一行排列；
键盘 Tab 使用相同顺序。Zoom／Pan／Fit 不改变裁剪范围或 Project Truth。

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 已分配 | Start／End 手柄、范围滑块、秒数输入 | 改播放起止。范围始终有效且不为空。手势结束才保存。只改播放范围，不裁掉原音频。 |
| Loop 开 | Loop start 秒数输入 | 改循环起点，限制在播放范围内。 |
| Forward 循环 | Loop crossfade 毫秒输入 | 改循环接缝的交叉淡化。Ping-pong 没有这个输入。上屏不显示该值。 |
| 已分配 | Zoom Out／Zoom In／Fit／Pan Left／Pan Right | 缩小、放大、看全部、左右移动触摸区的波形窗口。只改视图。 |

### 4.3 Playback \{#playback\}

四个开关按两列分组：第一行 Loop 与 One Shot（Loop 开时为 Hold），第二行
Mute 与 Reverse。每个开关显示真实的 On／Off；辅助技术继续通过原有名称和
按下状态识别它们。Tab 按这个顺序访问，忙碌时沿用既有禁用规则。

| 操作 | 结果 |
| --- | --- |
| Loop／One Shot（Loop 开时此键叫 Hold） | 切换触发模式，组合见 [1.8](#pads)。之后的演奏按新模式。 |
| Forward／Ping-pong（Loop 开时） | 单向循环或往返循环。选 Ping-pong 时 Crossfade 隐藏并清零。 |
| Mute／Reverse | 静音或反向，立即保存。Mute 不删除已录入的事件。 |
| Volume／Pitch／Pan | 音量 −60 至 +6 dB（0.1），音高 −24 至 +24 半音（0.1），声像 −100 至 +100（1，显示 L／C／R）。拖动保留原手势，点数值按 [4.1](#sample-rules) 精确输入。 |
| Attack／Release | Attack 0–2000 ms，Release 0–4000 ms，步长 1 ms；点数值按 [4.1](#sample-rules) 精确输入。可以保存 0 ms，声音的 2 ms 防爆音下限不改变输入下限；0–2 ms 的读数显示 2 ms。One Shot 时 Release 不可用。 |

### 4.4 Tone / EQ \{#tone\}

| 操作 | 结果 |
| --- | --- |
| Tone | −100 至 +100，步长 1；负值低通，正值高通，−2 至 +2 为 Off。点数值按 [4.1](#sample-rules) 精确输入，不增加独立 LP／HP／BP 或 resonance 参数。 |
| 拖动 EQ 的三个点，或聚焦后按方向键 | 横向改频率，纵向改增益。低点和高点拖进 Cut 区时为切除。回到 0 dB 时该段不起作用。 |
| 中段：双击或双指触后上下拖动；聚焦后 Shift+↑↓ | 调 Q。普通拖动仍改频率和增益。手势结束保存一次，Escape 取消。 |
| 焦点在 EQ 点上时按 Delete／Backspace | 关闭这一段 EQ。不会删除 Pad。 |

空 Pad 在 Tone / EQ 页显示 Add Sample。

- 五色按新稿同步显示：DRUMS `#F2B584`、BASS `#DDF478`、MELODIC `#B6A0EC`、VOCAL `#95D4DF`、TEXTURE `#E5ADC4`。已有工程的自定义颜色索引保持不变；Pad、Sequence 和颜色选择器显示同一有效颜色。选中仍有白边和绿点，空槽，以及没有自定义颜色的未知类别，仍按既有规则显示中性色。

### 保留素材 ASSIGN \{#retained-asset-assign\}

音频会话尚未提供独立 `assignPad` 能力时，ASSIGN 禁用，原有 Sample 功能继续可用。

明确源和 A01–D16 目标。只发送一次新命令，原 UNKNOWN 不被重发、替换或推定成功。

| Cancel assignment／Escape | 退役未提交草稿和迟到列表，不调用 assign、stop 或 trigger，不改变 Truth／Undo。 |
| 确认前改变源／目标或页面、Pad、Project、session、System 上下文 | 原查询与确认失效；新草稿必须重新验证，不继承旧确认。 |
| 发出后离开 Sample 或改变上下文 | App 保留原始四字段请求与 owner，直到原始结果或未知耐久性；关闭界面不撤销已发出的命令。 |

| 回执丢失／无效或刷新失败 | 未知回执明确显示 unknown；已知保存仍为 committed；不自动重发或换命令 UUID。 |
| 原 UNKNOWN 后的新 session | 重新选择源和目标后才允许一个新操作；取消不发命令，原 UNKNOWN 提示和身份继续保留。 |

原素材、源 Pad 和被覆盖素材均保留。换成不同 Asset 时目标 playback 重置；
同 Asset 保留目标 playback，目标 colour 保留。Undo／Redo 和重开按现有 Truth 语义工作。
迟到结果仅保留原始 Project 身份；不会因新上下文值相等而变成新 Project 或 Pad 的结果。
模态输入阻挡与 N13 数值编辑取消仍复用既有机制，没有新增快捷键或全局输入层。

源码或 mock 不代替 Native／PCM、听感、实体输入、发布或部署证据。

### 4.6 文件导入：长源裁剪 \{#long-source\}

文件入口接受 WAV、MP3、M4A、AAC、FLAC 等，实际能读的格式取决于浏览器。保存的是统一格式的音频。

IMPORT AUDIO 面板覆盖右侧触控区；TARGET 始终来自本次导入捕获的 Pad，
竖屏旋转控制台时面板保持正向。源波形、Selection start／length、文件信息、
容量和错误在内部纵向滚动；Preview selection 与 Stop preview 分成两个入口，
每次 Preview 都从当前选段重新开始，Stop 可重复操作。界面不从本地按钮状态
推断音频仍在播放。Commit／Cancel 和底部 Delete Pad 保持可达；提交中仍保留
既有 Delete 和 Escape 取消边界。原生模态的背景锁定、焦点约束和返回焦点不变。

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 已解码 | Selection start／length 滑块 | 在源音频里选一段。长度受目标 Pad 和 Bank 的容量限制。只改草稿。 |
| 选段有效 | Preview selection／Stop preview | 本地试听或停止。不保存。 |
| 可以提交 | Commit selection | 把选段写入目标 Pad。成功后面板关闭，上屏显示新波形；失败时面板保留并显示错误。颜色规则与普通替换相同。 |
| 面板内 | Delete Pad | 删除所选 Pad 的声音，不只是取消这次文件选择。 |
| 未提交 | Cancel／Escape | 放弃这次导入，回到 Sample，原内容不变。 |

面板打开时背景不能操作。

### 4.7 Record Sample 面板 \{#capture\}

面板覆盖右侧触控区，录音阶段标题为 RECORD SAMPLE，保留录音的裁剪／保存
阶段为 RECORDED SAMPLE。TARGET 始终标明原 Pad，录音计时读取实际音频帧。
Stop、Commit 和 Close 不随详细信息滚出面板；权限拒绝、设备变化及保存失败
仍可在内部纵向滚动查看。竖屏旋转控制台时，面板内容保持正向，水平裁剪
方式不变。它仍是原生模态弹窗，背景锁定、键盘焦点约束和关闭后返回焦点
继续有效；重新定位不会重建录音状态。

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 空闲或权限被拒 | Record into Pad | 请求麦克风权限并开始录音，显示输入电平、波形和时长。其他录音进行中时不可用。 |
| 录音中 | Stop | 停止录音，进入裁剪。不会自动保存。 |
| 录音中 | Continue in Sequence | 进入 Sequence，面板在后台继续录音。按原目标 Pad 可停止，之后裁剪面板覆盖在 Sequence 上。 |
| 裁剪中或保存失败 | Start／End 手柄、范围输入或方向键 | 选择要保存的片段，阴影、起止和时长同步。Escape 取消正在进行的拖动或按键修改。 |
| 裁剪中或保存失败 | Crop to selection | 丢掉选区外的音频，只留选中部分。尚未写入 Pad。 |
| 裁剪中或保存失败 | Commit | 把选段写入原目标 Pad。失败时录音保留，可以重试；“已保存但声音未准备好”与“保存失败”分开提示。 |
| 裁剪中或保存失败 | Discard | 丢掉这次录音，原内容不变。 |
| 任意 | Close／Escape | 停止麦克风并关闭面板，不保存。 |
| 录音中失焦、隐藏、设备变化或达到容量上限 | 自动停止 | 保留已录片段并说明原因，可以 Commit 或 Discard。自动停止不等于保存。 |

- 录音期间，所选 Pad 显示 Capturing。
- 再按原目标 Pad 会停止录音，不会演奏它。
- 按其他已分配的 Pad 照常演奏，不改变采样目标。
- 面板是弹窗，背景不能操作；Continue in Sequence 是唯一离开面板而不停止录音的出口。
- 这个面板没有试听已录片段的按钮。
- 与[按住空 Pad](#pad-capture)不同：这里 Stop 后必须 Commit；按住空 Pad 正常松手会自动尝试保存。

## 5. Sequence \{#sequence\}

**控件速查卡**

| 控件 | 在 Sequence 页的作用 |

| 16 个 Pad | 演奏并改变全机当前 Pad，Sample 编辑对象同步；非录音时不新增音符。录音中会录入，见 [1.3](#transport)。Record Sample 武装期间保持其目标。 |

| 触摸区 | EDIT（默认）和 SETUP 两层。 |

联动规则：

- ↑↓ 跨过 Bank 边界时自动换 Bank，上屏窗口移到能看见当前 Pad 的位置，已有的音符选区保留。
- ENC1 和触摸网格的横向滚动是联动的；ENC2 只滚上屏。
- 音符改动保存后，上屏和网格同时更新。
- 拖动 SETUP 的 Tempo／Swing 时，上屏立即显示草稿值；取消后回到已保存值。
- 打 Pad 的同时，播放头照常前进。

### 5.2 SETUP \{#sequence-setup\}

Tempo 与 Swing 纵向排列，各自使用整行宽度；Tempo 下方是 −1 BPM／TAP／+1 BPM，
保留 ENC3 提示，Swing 仍可逐步加减。BARS 与 SEQ SNAP 的标题位于各自选项上方，
Double Up／Copy／New 同行；Quantize 与 Metronome 显示当前 On／Off。
内容随整个触摸区纵向滚动。新建 Pattern 的长度表单打开时，TAP 沿用原规则暂时隐藏，
取消或创建后恢复。

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 非录音、非命令处理中 | TEMPO 滑块、−／+ | 40–240 BPM。滑块松手保存；按钮每次 ±1。播放中也能改，按引擎的生效边界更新。 |
| 同上 | SWING 滑块、−／+ | 50–75%。滑块松手保存；按钮每次 ±1。作用于整个 Pattern。 |
| Tempo／Swing 拖动中 | Escape、手势取消、换编辑对象、打开 System、开始录音 | 放弃草稿，回到已保存值；之后晚到的松手不会保存。 |
| 非录音、非命令处理中 | TAP | 按连续点按的间隔算 Tempo。第一次点按只是起点，有了有效间隔才保存。 |
| 停止 | BARS 1／2／4／8 | 改**当前** Pattern 的长度。变长补空小节；变短删除或截短越界音符。点当前长度不改。 |
| 停止，长度小于 8 | DOUBLE UP | 长度加倍并重复已有音符。到 8 小节时不可用。 |
| 停止 | COPY | 复制当前 Pattern 并切到副本。不同于 Project 的 DUPLICATE。 |
| 停止 | + NEW → 长度 1／2／4／8 → CREATE | 新建空 Pattern 并切过去。选长度不改旧 Pattern；CANCEL 只收起表单。 |
| 非录音、非命令处理中 | QUANTIZE | 开关录音量化，Perform 上屏显示新设置。不重写已有音符。 |
| 任意 | SEQ SNAP 1 BEAT／1 BAR／SEQ END | 选择之后播放中切换的边界；默认 1 BAR。Sequence 与未开演出录制的 Perform Launch 共用，重开恢复设备偏好，不改 Project 或 Undo。OFF 与录音中切换另有后续 Task。 |
| 任意，包括录音中 | METRONOME | 开关节拍器。这是本设备的设置，不保存到 Project；只在 Pattern 播放时发声。 |
| 任意 | Playback details → Refresh playback | 重新读取 Sequence、Project 和播放状态，核对未确定的命令，必要时恢复。不会再切一次 Play 或 Record。 |

SEQ SNAP 决定切 Pattern 的时机，Grid tools 的 Snap 决定网格编辑吸附，QUANTIZE 决定录音量化，三者独立。修改 SEQ SNAP 影响下一次切换请求，不改已经排队请求的边界。1 BEAT／1 BAR／SEQ END 到边界后，新 Pattern 从开头开始；停止播放清除尚未生效的排队。

## 6. Perform \{#perform\}

**控件速查卡**

| 控件 | 在 Perform 页的作用 |
| --- | --- |
| ENC1／ENC2／ENC3 | 主组为 Cutoff（独立 Filter）／Delay／Reverb；FILTER 组为 Type（LP／HP／BP）／同一 Cutoff／Resonance；FX／MORE 组为 Crush／Stutter／Gate；Reverse 与 Cutter 只有触摸推子，没有旋钮。七段单值 FX 每格 10/1000、SHIFT 1/1000；Cutoff 按 20 Hz–20 kHz 对数走，粗调每格 10 个对数位置、SHIFT 细调 1 个；Resonance 0–100%。停转和换组保持值与手势。 |
| ↑／↓ | 静默选择上一／下一当前 Pad，A01–D16 首尾停止；空 Pad 也可选择，跨界同步 Bank，不触发声音、不写工程或历史。SHIFT 或 System 中不可用。 |

| 上屏 | PATTERN PLAYING／PATTERN QUEUED／PATTERN POSITION／Bank 与 Quantize 四栏，前三栏都来自全局 Pattern transport。全局播放状态、bar／beat、进度、Performance phase、已分配槽数仍可见。独立 launch cue 保留 Performance pending launch／ACKNOWLEDGED 回执；它不覆盖 PATTERN QUEUED，也不代表 Performance 持续播放或录音时钟。 |
| 触摸区 | Live、Slots、Takes、Replay 四个子页；缺少能力时显示还在等待音频或录音存储。 |

- 页首提示和录制状态里重复的最近一次 Launch 文字已合并到上屏；Launch 键及分组旁的提示保留。
- 离开 Perform 会结束演出录制和 Replay，见 [1.2](#pages)。

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 任意 | Live／Slots／Takes／Replay | 切子页并回到页顶。录制、回放、HOLD、表单和 More 展开都保留。FX 推子按住时暂不能切。 |
| Live | 1–4／5–8／9–12／13–16 | 选择显示哪四个 Pattern 槽。不触发 Launch。其他组的槽仍显示 Queued／Playing。跨子页保留。 |
| 演出录制中 | Pattern Launch 01–16 | 预约切到该 Pattern，状态 Queued → Playing。上屏在真正切换前仍显示原 Pattern。Launch 会被记录；空槽是一段静音。 |
| 播放且未录音 | Pattern Launch 01–16 | 按同一设备 SEQ SNAP 预约在下一拍／下一小节／Pattern 结束边界切到该槽的 Pattern，槽位显示 Queued，正在播的 Pattern 显示 Playing；上屏的 QUEUED SLOT 同步显示排队目标。Sequence 排队到未分配槽的 Pattern 时，上屏显示 QUEUED PATTERN NN。bar／beat／进度使用正在播放的 Pattern 长度。空槽不做任何事。 |
| 停止 | Pattern Launch 01–16 | 直接选中该槽的 Pattern，之后按 Play 从它开始。空槽不做任何事。 |
| 全局 Pattern 录音但没有演出录制、transport 命令处理中或状态未知 | Pattern Launch | 不可用；全局 Pattern 录音中切换已批准、尚未交付，见[第 2 章](#planned)。 |
| 演出录制正在启动、停止、保存、丢弃或处于失败阶段 | Pattern Launch | 暂不可用；等该操作完成或恢复。稳定的 idle／stopped 才可按全局 transport 选择／预约，recording／flushing 走演出 Launch。 |
| 可用时 | Filter／Delay／Reverb 推子 | 按下、移动、松开即实时效果；Delay／Reverb 显示百分比，Filter 是独立滤波的 Cutoff，按 Core 读回显示 Hz（OFF／LP／20 kHz／0% 起；producer 不可用时不从百分比反推 Hz，FILTER 面板如实显示 unavailable）。演出录制中同时记录；触摸与旋钮调同一参数时共用拥有的手势。 |
| 可用时 | FX / MORE 与 FILTER | FX / MORE 展开或收起 Stutter、Gate、Reverse、Crush、Cutter 五个触摸推子，同时把旋钮组切到 Crush／Stutter／Gate；FILTER 打开独立滤波面板（LP／HP／BP 类型段、Cutoff、Resonance）并把旋钮组切到 Type／Cutoff／Resonance。进入 FILTER 组不调用任何 producer、不改变声音；旋钮效果保持；收起 MORE 或 FILTER 时释放其触摸推子上未结束的手势。HOLD 下松开由 Core 冻结，面板读回 frozen。 |
| 可用时 | HOLD | 开关 FX 保持：松开推子后效果按规则保留。与 Sample 的循环 Hold 不同。 |
| 监听音量已恢复且可用时 | MASTER | 0–100% 的本设备监听音量，与 ENC4 共用，下次打开恢复。不写工程，不改变录音、重采样或导出电平，也不随演出录制／回放变化。 |
| 可录制，其他录音空闲 | Record Performance | 开始记录演出操作和主输出 WAV；Launch 变为可用。准备失败时显示原因。 |
| Takes，录制中 | Flush Performance | 立即写出本轮已记录的操作。不停止，也不另存音频。 |
| 录制中 | Stop Performance | 结束录制，等待保存或丢弃。不停止全局 Pattern。停止尚未完成时 Launch 不可用；完成后按全局 transport 的停止／播放状态选择或预约，不再写入刚停止的演出。 |
| Live，已停止 | Review recording | 进入 Takes 处理录音。 |
| Takes，已停止 | Performance name | 修改名称。保存或丢弃进行中时只读。名称为空时不能保存。 |
| Takes，已停止且有名称 | Save Performance | 保存演出和 WAV，Replay 出现新条目。点 Save 前不算保存。WAV 关联失败时出现 Retry WAV bind。 |
| Takes，已停止 | Discard Performance | 丢弃当前待保存的演出。不删除已保存的演出。 |
| Takes，有 WAV | Export Performance WAV | 下载这次的 WAV。不产生作者编辑。 |
| Takes，关联失败 | Retry WAV bind | 只重试关联 WAV，不用再演一次。 |
| Replay 有条目，或任一子页回放中 | Replay／Stop Replay | 回放或停止。回放不会录进 Pattern；上屏仍显示全局 Pattern。Stop Replay 将 FX 归中、关闭 HOLD 并清空演出 Launch 状态，监听音量保持。 |
| Replay，有演出恢复候选 | Apply recovery／Discard recovery | 恢复演出（自动收尾未松开的 Pad），或丢掉候选。丢候选不删除已保存的演出。 |
| Live／Slots／Takes，有恢复候选 | Review recovery | 进入 Replay 查看。FX 推子按住时不可用。 |
| Slots，演出录制空闲 | Pattern assignment／slot、Clear slot、Move from／to 下拉 | 选择要分配、清空或移动的槽。还没生效。 |
| Slots，演出录制空闲 | Assign Pattern／Clear Pattern／Move Pattern | 把 Pattern 放进槽、清空槽或移动。源和目标相同时 Move 不可用。录制非空闲时这些编辑都不可用。 |
| 任意 | Recording details 折叠项 | 只读：WAV 录制和关联状态，以及未结束的 Pad／FX 手势数和 HOLD。 |
| Slots，或有 Replay 的任意子页 | Project details／Replay details 折叠项 | 只读：Project 修订号，或回放状态和 Neutral FX。 |

### 7.1 Sound Sets \{#soundsets\}

触摸区分为 **Browse / Details / Target / Review** 四步。

- Browse 顶部标记 Catalog；单列卡片显示真实名称、声音数量和许可，Refresh Catalog 与 Back to Project 在列表底部。Catalog 不可达时显示本 Workspace 的缓存提示；卡片没有独立的“已缓存／在设备上”状态。
- Details 顶部显示所选 Set 的名称和实际声音数量；demo 与 Stop 在声音列表之前。全部 16 槽分成两列，左列 01–08、右列 09–16；空槽只有说明，不能试听。Choose install target 在列表之后；Set and sound details 可展开查看发布者、版本、下载大小及各声音的角色、采样率和声道。
- Target 选择安装到哪个 Bank，再按 Preview mapping；目标说明明确不改变演奏 Bank。
- Review 显示只读的 4×4 映射方案、全局冲突处理和确认；Install 在 Refresh mapping 之前。
- 许可和署名在 Details、Target、Review 都可见。
- 只有触摸区整体纵向滚动，步骤条始终可达。
- 切步骤不重新读取详情、不安装、不停止试听。
- 回到 Browse 时保留所选 Set，焦点和列表位置回到原来的 Inspect 按钮。
- 换目标 Bank 会清除旧方案和冲突选择。
- 预览或安装进行中，步骤、目标和冲突选择都锁定。

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 可以查询 | Refresh Catalog | 重新列出可用和不可用的 Set。离线时显示本设备缓存。 |
| 有 Set | Inspect Set | 读取详情：名称、许可、全部 16 槽和可用的 demo；声音数量以占用槽数为准。 |
| 未在请求中 | Browse／Details／Target／Review 步骤键 | 切步骤。没选 Set 时只有 Browse；没有方案或安装结果时 Review 不可用。 |
| Details | Choose install target | 进入 Target。 |
| 有 demo 或声音 | Audition demo／声音名称按钮 | 试听，不需要先安装。再次试听替换上一次。没有持续的“正在播放”状态，出错时提示。 |
| Details | Stop audition | 停止 Set 试听。不停止全局 Pattern。 |
| Target | Install target Bank A–D | 只选安装目标，不改左栏的演奏 Bank。 |
| 已选 Set 和目标 | Preview mapping | 显示目标 Bank 16 个槽的方案：Install／Occupied／Empty source／Unmapped。方案格不能演奏。空声音不会清掉 Pad。 |
| Review，未在请求中 | Refresh mapping | 按当前目标和 Project 重新生成方案，冲突选择需要重新确认。不安装。 |
| 方案有冲突 | Keep occupied／Replace occupied | 为所有冲突槽选择同一个保留或替换策略，分组标题显示受影响的 Pad 数量；不能逐槽混用。不选就不能安装。 |
| 方案可以提交 | Install into Bank | 按确认的方案安装，显示 Installed 或冲突、失败。若目标是当前 Bank，Pad 声音和颜色随即更新。空的 Set 槽不清除原 Pad；Replace 时颜色按普通替换的规则保留。 |
| 详情或错误 | Browse／Dismiss | 返回列表或关闭错误。不撤销已完成的安装，不停止试听。 |

[2026-10-13 Interaction UI 决定](https://github.com/endaye/lmdj/blob/main/docs/prd/decisions/2026-10-13-creator-interaction-ui-baseline.md)保留全局 Keep／Replace 策略；图稿中的单槽示例不改变这个边界。试听没有可据以显示持续播放灯的状态，Stop 直接交给 Host 判断并执行。

安装总是用预览时的目标和 Project 版本；如果 Project 之后变了，安装被拒绝，需要 Refresh mapping 后重新确认。

### 7.2 Slice \{#slice\}

触摸区先显示 Provider、Source，再显示权限和 Public audio 声明、Analyze。

Adopt 在列表之后，Refresh 与 Back to Sample 位于底部同一行，Discard 单独置后。

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 支持 Slice | Provider 下拉／Grant analysis permission | 选择分析服务、授予分析权限。这是本设备设置，不写入 Project。 |

| 分析中或中断 | Cancel analysis | 取消这次分析。之前的结果和已采用的 Pad 不受影响。 |
| 有候选 | Preview slice／Stop preview | 试听或停止一个切片。不分配。音频未启动时提示先打一个 Pad。 |
| 有候选 | Add target、Slice／Bank／Pad 下拉、Remove | 编辑“一个切片 → 一个目标 Pad”的列表。不换演奏 Bank，不保存。 |

| 有分析记录 | Refresh slices and Project | 重新读取 Project 和候选，解除已核对的不明状态。不自动重试 Adopt。 |
| 有候选 | Discard slices | 停止试听，丢掉候选。不撤销已采用的 Pad。 |

## 9. 跨页的录音、恢复与错误 \{#cross-page\}

这些控件出现在当前页面的触摸区里，与页面无关。

| 状态 | 操作 | 结果 |
| --- | --- | --- |

### A.1 术语对照 \{#terms\}

正文用用户语言；对应的实现术语如下。

| 正文说法 | 实现术语 |
| --- | --- |
| 生效、保存后显示 | 操作成功并完成**回读**（re-read）后的**投影**（projection）。等待、失败或 publication pending 都不算完成。 |
| 作者编辑、保存 | 一次 authoring 提交，Project **修订号**（revision）加一。只改选中项、视窗、草稿或设置表单不加修订号。 |
| 保存本轮录入的事件 | Pattern 事件录音的**结算**（settle）与回读。 |
| 命令处理中 | 传输命令正在结算；灯与上屏等权威状态回读，可能显示 publication pending。 |
| 已保存、声音未准备好 | 作者修订已保存，Runtime 尚未发布（prepare／cook 失败，stale runtime revision）。 |
| 控制台暂时不接受操作 | Undo/Redo 执行时整个控制台 inert。 |
| 背景不能操作 | 模态弹窗把背景设为 inert；它不屏蔽全局音乐键。 |
| Bank 键不会切换 | 控件仍显示，但 reducer 拒绝 `bank-selected`。 |

### A.2 精确条件与实现细节 \{#conditions\}

**左栏与传输**（`app.tsx`）

- Play/Stop 可用：`transportReady && !transportBusy`。`transportReady` 要求 Pattern transport 会话、监听音量恢复就绪、Project ready、可开始手势，且音频 running，或 Runtime 处于 audio-suspended 且音频 inactive／suspended。
- Record 可用：在 Play 条件之外，还要求空 Pad 采样空闲、Record Sample 面板为 idle／permission-error、演出阶段为 idle／saved／discarded。
- Play/Stop 与 Record 在 audio 未运行时先 `activateAudio`，等唤醒成功且 Project、会话和手势 epoch 未变才提交意图。
- 页面键：`selectMode` 关闭 System、`clearPressed()`、清 SHIFT；离开 Perform 时先 `performController.leave()`。
- Sequence 键：`isSequenceSession && project ready && current !== null`。
- Perform 键：只要求 `project ready && current !== null`。Perform 触摸区的能力就绪条件另行要求 performController 与 capture storage，见 `app.tsx` 的 `performEnabled` 与挂载路径。
- Bank：`selectBank` 先取消旋钮草稿、清按压与 SHIFT，再 dispatch；`isCreatorActionAllowed` 不允许时 reducer 拒绝。Runtime／Project 未就绪或 `transfer.phase !== "idle"` 时拒绝；播放／录音本身不拒绝。Bank 不 dispatch `slot-selected`，保留 `sample.selectedSlot`；`selectCurrentPad` 以它作为全机当前 Pad，尚未选中时回退到当前 Bank 首槽。
- ↑↓ 与 Bank 使用同一允许条件（`padNavigationAvailable`）。
- 历史 hook 用 `navigationKey` 区分页面切换与权威刷新；ready history 可保留，blocked/unknown、失败或曾访问本地 authoring owner 的保守路径仍 inspect。Project/session/revision、publication pending、Performance recovery 变化和窗口 focus 保留各自重新核对，不把修复理解成缓存所有历史结果。
- ← → 切 Pattern：`patternStepOpen` 要求 Sequence 页、未锁定设置（transport busy 或录音）、步进基准 Pattern 索引有效；播放中不再关闭。步进基准在播放中取排队的切换目标，否则 `currentPatternId`，停止时取所选 Pattern；播放中的按下走 `requestTransportPatternSwitch`，停止时走 `snapshot.reload`。SHIFT 关且非 Sequence 时，Undo/Redo 键保持禁用。

**旋钮**（`state/encoder_input.ts`、`sample_encoder.ts`、`monitor_volume_preference.ts`、`app.tsx`）

- `ENCODER_IDLE_COMMIT_MS = 400`；Sample 同一 Pad 多参数与 Sequence BPM 停转后合并一次 authoring 提交／Undo。回到起点不提交。Perform 与设备监听不使用该作者保存计时。
- 上一次提交还在路上时，新一轮从该请求值开始；提交失败后 `forget()`，下一轮从 Truth 开始。
- 作者锁定／录音／传输结算、离页、打开 System、切 Pad／Project／所选 Pattern、Esc 或历史前，通过 `cancelPendingEncoders` 和各目标的 cleanup 取消尚未提交草稿；已发出请求保留真实结果。
- 网页拖动每 8 px 一格，滚轮累计 50 px 一格（`physical_controls.tsx`）。
- [2026-10-09 旋钮决定](https://github.com/endaye/lmdj/blob/main/docs/prd/decisions/2026-10-09-contextual-encoders-and-monitor-volume.md)已确认逐页映射、SHIFT 细调、设备监听记忆和 400 ms 生命周期；[三页普通方向映射](https://github.com/endaye/lmdj/blob/main/docs/prd/decisions/2026-10-11-creator-navigation-and-live-mute-tails.md)已批准，实现与验收待完成，[#1822](https://github.com/endaye/lmdj/issues/1822)仍保留其他 SHIFT 提案。BPM 可听预览未完成，不能用读数测试替代。
- ENC4 在 `encoderBindings` 中独立于页面绑定，偏好恢复绑定 Runtime session，后续转动覆盖旧恢复；`metronome_click.ts` 使用同一监听节点，位于 capture tap 之后。

**Pad 输入**（`pad_surface.tsx`、`input_controller.ts`、`input_adapters.mjs`）

- 键盘按物理 `code` 映射；全局键盘过滤只识别可编辑目标，没有独立的“弹窗打开即屏蔽”判断。
- 未完成的按压在 blur、hidden、pointercancel、切 Bank 或换页时清理。空 Pad 采样中断时封存为 review，而不是正常松手的自动提交；浏览器音频中断另有处理。
- 默认声音种子状态 Loading／Processing／Failed／saved-unavailable 时禁用该 Pad；内容可能仍显示旧投影。
- 空 Pad 采样的“待确认”在状态机中是 review → saving → idle，保存失败回到 review。

**Sample**

- 页面上的 range 参数：移动时预览，pointerup、键盘步进结束或 blur 时提交一次；Escape 或 pointercancel 取消。预览被拒绝会清草稿，晚到的 pointerup 不提交。精确输入使用 `sample_parameter_editor.tsx`，其内部 range 仅更新草稿，Apply／Enter 才保存；由 `sample_controls.tsx` 捕获保存值及上下文，render-time fence 拒绝 passive cleanup 前的过期 preview／submit。`SampleSurface` 将它注册到已有 contextual encoder pending／cancel，沿用 App cancellation／history hook 与 revision-fenced `sample.update_pad`；没有新计时保存或 App shortcut。
- Ping-pong 连带清 `loopCrossfadeFrames`。
- 替换声音时恢复样本播放默认参数，Pad 颜色 override 保留；Delete 清除 Pad 播放与颜色信息；Pattern 引用 Pad Slot，不因 Delete 改为 Asset 引用。
- 改色禁用条件（`padColourDisabledReason`）：录音中；传输结算中；Project 或 Runtime 未 ready；改色进行中、投影刷新中、Sample 有 pending action 或文件传输中；Sample 草稿未完成。相同 override 不提交。
- 长源导入写入归一化音频；不能把旧的“仅 PCM16 WAV”错误提示当作入口的全部能力。

**Sequence**

- 写入类网格手势在录音或投影回读中禁止开始；音符改动松手一次提交，边界按有效范围钳制。
- Refresh playback 按同一命令身份协调未确定的命令，不是再次反向切 Play/Record。

**Perform**

- Pattern Launch 在演出录制 recording／flushing 时记录为演出 launch 操作并等待权威确认；其他情况下只有 recording phase 为 idle／stopped、transport status 存在且未录音／未 busy 时才开放全局选择路径。播放时预约 `pattern.transport.switch`，停止时 `snapshot.reload` 选中，空槽不做任何事。starting／stopping／saving／discarding／failed 不开放 fallback。上屏由全局 Pattern 投影驱动，不把 queued 当作立即换曲；无演出事实时槽位的 Queued／Playing 改读 transport 的 `pendingSwitch` 与 `currentPatternId`。
- Filter／Delay 等推子是 engage → move → release 手势；非录制时走实时 FX，录制中同时记录演出 FX 操作。HOLD 按引擎 hold 规则保留。
- Save Performance 后 `bindingStatus` 可能需要 Retry WAV bind；不假装 WAV 已绑定。
- Replay 状态 playing／idle／neutral 与 resolved revision 独立回读；Stop Replay 请求停止并中和 replay 状态。

**Sound Sets 与 Slice**

- 安装使用预览时的 Bank 与 Project revision；Project 已变化时保留拒绝，Refresh mapping 后重新确认。安装后修订和 Asset 计数在 System 详情。
- Provider 选择与权限是 Workspace 设置，不写 Project Truth；Slice 分析结果是候选，不写 Project Truth。
- Adopt 结果不确定时先 Refresh，不自动重试。

**System 与恢复**

- Pad recording source 存在设备 `localStorage`。
- Project 打开需取得项目锁；Retry project 不强制夺锁；Continue here 的对方可 refused 或 unanswered，未答复不是授权。
