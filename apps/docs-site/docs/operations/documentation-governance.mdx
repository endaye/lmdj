## 单一来源
门户源码位于 `apps/docs-site`，事实来自 active manifests；独立手工 HTML 不再是正常发布源。
## 过程文档位置
设计与配套参考素材位于 `docs/design/`，实施计划位于 `docs/plans/`，跨会话交接位于 `docs/handoffs/`，完成报告与验证记录位于 `docs/quality/`。目录索引由 `docs/README.md` 维护；生成工具不决定文档归属。路径迁移更新 current 引用，已冻结版本页和来源证明保留原路径并通过其 Git revision 审计。

## 页面 Contract
每页声明 area、status、owners 与 source paths；构建拒绝缺失来源、非法状态和 current/history 边界泄漏。
## 版本更新规则
任何改变产品能力、Module/Host/Provider/Contract/Assembly/平台/发布流程的版本 Task，都必须同步对应页面和图；Product Build 或 Assembly 变化不能声明文档无影响。
## 快照规则
本地构建、普通 CI 和 PR Preview 只校验 current 页面，不创建永久快照。任何已分配并交付团队测试的 `canary`、`dev`、`beta` Product Build，以及 `stable` 发布，都必须冻结匹配的不可变快照；current main 始终标明非正式快照。
schema-2 快照把 37 页 current source、versioned sidebar、十张图的 20 个 HTML/SVG 资产和自认证 Git/source projection 元数据作为一个生成边界。版本页的卡片按 active doc ID 解析，图表按版本资产根解析；缺失、重复、越界、符号链接或哈希漂移都 fail closed。已有 schema-1 快照保持只读兼容，不回写为 schema 2。若 squash introducing tree 还包含冻结后的 mutable current/non-projection 更新，必须用 `scripts/docs-site.sh witness PRODUCT_BUILD INTRODUCING_REVISION` 生成反向差异；验证器只在临时 Git index 精确重建 raw source commit 已认证的 tree/commit 后才接受，不能重建、身份不匹配或被篡改的 witness 继续 fail closed，且不能改写不可变快照。
## 发布规则
Git 合入 main 触发 Cloudflare 构建；先通过完整 Portal check，再验证同一 Git SHA 的版本 Preview，发布同一个 version ID 并验证生产 smoke。手工本地上传不能替代 Git 生产流程。

## CI 影响检查
Pull Request 必须声明 `Documentation impact: required` 或 `none`。需要更新时，changed files 必须包含 current 门户页；无需更新时必须给出具体理由且不能制造空文档 churn。完整检查还要求当前 Product Build 的快照与 source revision、source-rebuilt Product/Assembly facts、37 页清单、sidebar、版本图表、Channel、freeze time 和 introducing commit 一致；来源关系只接受 direct-parent、byte-identical squash projection，或能精确重建已认证 source tree/commit 的显式 squash witness。

## Cloudflare PR Preview 试点

PR Preview 使用隔离构建和独立可信发布两个 workflow。构建绑定 PR head，
不接收部署凭据；发布端从 GitHub API 核实 run、artifact 和当前 head，验证
静态归档后生成固定配置，只上传到 `portal-preview` 的版本地址，并在页面、
响应头和文件摘要检查通过后回写 `Cloudflare Portal Preview` 状态。

试点默认关闭。仓库变量 `CLOUDFLARE_PREVIEW_PILOT_BRANCH` 必须显式指定一个
同仓库分支；启用前需落实临时 runner 预算、`portal-cloudflare-preview`
Environment 凭据以及现场验收。代码合并和本地测试不代表试点已启用或验收通过。
旧 Netlify 检查的退役仍由迁移清单单独追踪。
